Целью проекта "Прометей" является создание мощного инструмента для информационной безопасности, который облегчит задачи в данной сфере и поможет бороться с киберпреступностью.

Актуальность темы заключается в том, что перед руководством современных компаний остро стоит проблема организации информационной безопасности, так как взлом уязвимой информационной системы наносит организации как денежный, так и репутационный ущерб

Мультитул "Прометей" для обеспечения информационной безопасности — это интегрированная система на базе искусственного интеллекта, предназначенная для обнаружения, анализа и реагирования на киберугрозы в организациях. Проект состоит из трёх ключевых модулей: антифишинг-системы, системы форензики и помощника для SOC (Security Operations Center). Каждый модуль решает отдельную задачу в цепочке защиты, работая с использованием открытых моделей машинного обучения.

ИИ антифишинг-система отвечает за автоматическое обнаружение фишинговых атак через электронную почту и веб-страницы. Она анализирует тексты писем, метаданные и ссылки на предмет подозрительных признаков, используя DistilBERT для обработки текстов, а также специализированные архитектуры вроде URLNet для анализа структуры URL. Для обучения и настройки модели используются открытые датасеты фишинговых атак OpenPhish .

ИИ система форензики базируется на алгоритме кластеризации DBSCAN и предназначена для анализа логов, сетевого трафика и действий пользователей. Она позволяет группировать события по схожести и выявлять аномалии — выбросы, которые указывают на возможные инциденты безопасности. Реализация построена на стандартных библиотеках Scikit-learn и специализированной библиотеке для поиска аномалий PyOD. Дополнительно, для централизованного сбора и визуализации логов может в будущем использоваться стек ELK.

ИИ SOC помощник помогает специалистам Центра мониторинга безопасности обрабатывать инциденты, ускоряет рутинные задачи и предлагает рекомендации на основе накопленных данных и сценариев реагирования. В качестве базовых моделей используются LLama3. Для создания диалоговых систем на их основе используются фреймворк Haystack, позволяющий строить более сложные пайплайны обработки запросов и автоматизировать анализ инцидентов.

Для развертывания мультитула "Прометей" можно рассмотреть несколько архитектурных вариантов в зависимости от потребностей организации. Локальная архитектура предполагает установку всех модулей на физических серверах или в локальном виртуализированном окружении без выхода в Интернет, что обеспечивает максимальную приватность данных. Используется контейнеризация через Docker, оркестрация Kubernetes и специализированные серверы с GPU для ускорения вычислений. Данные инцидентов хранятся в бд.

Гибридная архитектура сочетает локальное в частное облако. Между локальной инфраструктурой и облаком устанавливается защищённое VPN-соединение. Kubernetes в облаке обеспечивает масштабируемость, а Redis поддерживают высокую скорость обмена сообщениями между модулями.

Полностью облачная архитектура подходит для организаций, готовых доверить работу частным облачным провайдерам. В этом случае все модули разворачиваются в изолированных Kubernetes-кластерах с использованием управляемых сервисов, таких как ElasticSearch as a Service и облачные GPU-инстансы. Это позволяет быстро масштабировать систему в зависимости от нагрузки, однако требует высокой зрелости процессов безопасности и защиты данных в облаке.

Во всех вариантах архитектуры обеспечивается централизованная аутентификация пользователей через собственный OAuth2-сервер, обмен данными между модулями организуется через API REST с двухсторонней аутентификацией. Централизованное хранилище логов и инцидентов позволяет проводить аналитику и построение отчётов. Обновление моделей искусственного интеллекта производится через отдельные безопасные каналы.

Таким образом, мультитул "Прометей" может быть гибко адаптирован под разные требования организаций, обеспечивая надёжную защиту от угроз и повышая эффективность работы подразделений информационной безопасности.
