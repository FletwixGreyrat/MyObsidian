
IP Address (Internet Protocol Address) - адрес интернет протокола, то есть уникальный адрес конечного  узла в сети. Это как домашний адрес. Каждому цифровому устройству (ПК, смартфону, планшету) назначается IP-адрес, без него устройство нельзя найти и обратиться к нему. 

Существуют две версии IP адресов: IPv4 и IPv6 (о ней чуть позже, чтобы не распыляться). IP-адрес IPv4 представляет собой число размером 32 бита, записанном в , но видим мы его в десятичном , потому что так удобнее. Если точнее, то айпи состоит из четырех групп по восемь битов, именуемых октетами. Каждая группа может представлять число от 0 до 255. 

IP-адреса обычно делятся на три класса, которым соответствует свой диапазон (в след конспекте рассмотрим подсети и маски подсети, которые отличаются в зависимости от класса IP-адреса). 

Система IP-адресов имеет свои ограничения, и самое основное из них связано с тем, что адресов банально не хватает на все устройства. Система IPv4 имеет 4 миллиарда 300 миллионов ip адресов, а людей в мире 8 млрд., а устройств еще больше. В результате чтобы решить эту проблему была разработана система для повторного использования группы IP-адресов, которые будут использоваться в локальной сети и которые нельзя использовать в сети. Эти адреса можно использовать снова и снова в каждой локальной сети. Эти частные адреса включают в себя диапазоны IP-адресов 192.168.0.0 - 192.168.255.255, 10.0.0.0 - 10.255.255.255, 172.16.0.0 - 172.16.255.255

Чтобы узнать свой локальный ip адрес, нужно прописать ipconfig для Windows и ifconfig для Linux, а для того чтобы узнать айпи домена, нужно написать nslookup {домен}

	Пример: nslookup google.com`

DHCP - Dynamic Host Configuration Protocol, протокол динамической настройки узла, отвечает за динамическое назначение ip адреса. Это означает, что у тебя не один и тот же ip адрес все время. Как правило, эти назначение ip адресов происходят в локальной сети. Когда устройство подключено к локальной сети, оно должно запросить ip адрес. Это устройство, отправляя запрос на сервер DHCP, который затем назначает айпи адрес этой системе на фиксированный период времени, этот период времени называется аренда

NAT - Network Address Translation, преобразователь сетевых адресов, это механизм в сетях модели TCP/IP, позволяющая преобразовывать ip адреса транзитных пакетов. Иными словами - это протокол, посредством которого внутренние частные ip адреса транслируются на внешние общедоступные ip адреса, которые можно направить через Интернет в пункт назначения. Устройство NAT принимает запросы с внутренней машины, затем оно записывает ip адрес этого устройства в таблицу и преобразует айпи адрес во внешний айпи адрес маршрутизатора. Когда пакет возвращается из пункта назначения, устройство NAT просматривает свою таблицу исходных запросов и перенаправляет пакет на внутренний айпи адрес системы, который сделала исходный запрос в локальной сети. При правильной работе пользователи не видят весь этот процесс, а многие не знают, что он вообще существует

Порты - это подадрес. Если IP - это название улицы и номер дома, то порт - номер квартиры. Точно так же айпи адрес приводит нас к нужному компьютеру, а порт - к нужной службе. Всего существует 65535 портов, первые 1024 из них обычно называют общими. Нет необходимости запоминать их все, но толковый сисадмин или пентестер должен знать основные:
- 20 FTP
- 21 FTP
- 22 SSH
- 23 Telnet
- 25 SMTP
- 53 DNS
- 69 TFTP
- 80 HTTP
- 88 Kerberos
- 110 POP3
- 123 NTP
- 135 MRPC
- 137-139 MNetBIOS
- 143 IMAP
- 161 SNMP
- 389 LDAP
- 443 HTTPS or HTTP over SSL
- 445 SMB
- 500 IKE
- 514 syslog
- 3389 RDP

Если процесс постоянно использует один номер порта, то такой порт называют открытым

Если процесс получил номер порта у операционной системы, то есть открыл порт и держит его открытым для приема/передачи данных, это называется прослушиванием порта
