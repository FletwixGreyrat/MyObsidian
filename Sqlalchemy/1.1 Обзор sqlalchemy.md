Sqlalchemy -- это набор инструментов для работы с базами данных, который состоит из двух частей: Core и ORM.

Уровни алхимии (сверху вниз):
- SQLAlchemy ORM
- SQLAlchemy Core
- DBAPI (по факту не часть алхимии, а та часть, к которой она будет постоянно обращаться, какой-то драйвер)

SQLAlchemy ORM:
- Объектно-реляционная схема (ORM)

SQLAlchemy Core:
- Схемы/Типы
- Язык SQL-запросов
- Машина соединений
- Множества соединений
- Диалекты

У любой базы данных должен быть драйвер, который позволит как минимум открывать соединения и с ними работать, а алхимия просто абстрагирует эти соединения. То есть, независимо от того, с каким драйвером будем работать, работа с алхимией будет примерно одинаковая, поэтому нетрудно перейти с одной СУБД на другую.
