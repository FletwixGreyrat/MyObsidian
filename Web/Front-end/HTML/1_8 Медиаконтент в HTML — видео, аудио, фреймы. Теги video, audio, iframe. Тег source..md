
Под медиаконтентом подразумеваются изображения, видео, аудио и фреймы. С изображением и тегом img можно ознакомиться в конспекте 1_6. 

Тег video - выводит на странице плеер для вывода видео. Для управления плеером нужно указать в нем атрибут controls, иначе никак не получиться взаимодействовать с видео (можно добавить свои элементы, используя CSS для стилизации и JS для функционала)

Для видео можно менять ширину и высоту через атрибуты width и height. Атрибут autoplay запускает видео автоматически. Атрибут muted запускает видео без звука. Некоторые браузеры не позволяют работать autoplay без muted. 

	Интересно: на сайт Ютуба в браузере Chrome это ограничение не распространяется

Атрибут loop позволяет зациклить видео сразу после его завершения. 
Атрибут poster отображает обложку видео, которая будет видна, пока не включится видео, если его не указать, то будет виден первый кадр его видео 
Атрибут playsinline меняет стандартное поведение видеоплеера на мобильных устройствах при загрузке страницы. Вместо автоматического открытия в полноэкранном режиме, оно будет открываться в стандартных рамках своего элемента


Тег audio выводит на страницу компактный аудиоплеер, функционал которого так же зависит от атрибута controls и от браузера. К нему применимы все атрибуты тега video

Тег iframe позволяет вывести на страницу вашего сайта виджет с каким-то функционалом, например, виджет погоды, интерактивную карту, видеоплеер ютуба и многое другое (даже другой сайт). 

iframe имеет множество атрибутов, но в его полную анатомию вдаваться не надо, вот основные атрибуты:
- src
- width
- height
- frameborder
Последний показывает наличие или отсутствие рамки вокруг фрейма (0 1). Атрибут устаревший, добавлять его самостоятельно не нужно
