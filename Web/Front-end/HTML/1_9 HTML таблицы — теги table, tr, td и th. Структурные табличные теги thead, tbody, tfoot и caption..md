
Таблицы в html - это далеко не набор тегов для отображения таблиц. Это целая эпоха так называемой табличной верстки, когда весь контент сайта буквально верстали как таблицу, помещая информацию в строки и ячейки таблицы. Это делали потому, что CSS раньше был сильно ограничен и расположить элементы сайта там где требовалось по макету было очень сложно

Способ верстки на таблицах уже давно неактуален, ведь силами CSS все это делается гораздо удобнее, однако для табличных данных теги таблиц можно и нужно использовать

Тег table - обязательный тег любой таблицы, оборачивает все остальные табличные теги

Тег tr - используется для выделения строк в таблицах. Как и table, он является обязательным, так как ни одна таблица не обходится без строк. Они располагаются внутри тега table

```html
<table>
    <tr>text</tr>
    <tr></tr>
    <tr></tr>
    <tr></tr>
    <tr></tr>
</table>
```

Тег td - используется в качестве обычной ячейки таблицы, располагается внутри тега tr
Тег th - используется в качестве заголовочной ячейки таблицы, располагается внутри тега tr. По умолчанию браузер выделяет содержимое этого тега жирным шрифтом, это единственное визуальное различие тега th от td

Помимо вышеприведенных тегов таблиц рассмотрит также дополнительные структурные теги таблиц.

Тег caption - указывает общий заголовок таблицы, располагается строго внутри тега table и сразу после открывающей ее части, такой тег в таблице может быть ровно один

Тег thead - выделяет верхнюю часть таблицы, оборачивая одну или несколько строк. Обычно, в верхней части таблицы располагается так называемая "легенда" в заголовочных ячейках th, которая объясняет, что за информация хранится в этом столбце

Тег tbody - выделяет основную часть таблицы

Тег tfoot - выделяет нижнюю часть таблицы. Обычно, это какое-то "Итого" с результатами из основной части таблицы (tbody). 

Если визуально таблицу из макета можно поделить на части, то лучше и на уровне разметки обозначить части структурными тегами. Это поможет не только вам как разработчику лучше читать написанную разметку, но и пользователю скринридера будет лучше, так как для них он четко обозначит основные части таблицы, а не пачками прочитает все ячейки без разбора

Теперь немного поговорим о способе объединения ячеек. Не все таблицы стандартные и не все содержат одинаковое количество ячеек в каждом столбце. В этом нам помогут два атрибута. 

Атрибут colspan - указывается для ячеек таблицы (тегов td и th), чтобы соединить несколько ячеек по горизонтали

Атрибут rowspan - указывается для ячеек таблицы (тегов td и th), чтобы соединить несколько ячеек по вертикали

	Интересный факт: таблицы можно вкладывать друг в друга, но сейчас так делать не стоит
