
 Атрибут required  делает поле формы обязательным для заполнения, его можно применять к тегам select, textarea, input практически со всеми вариациями type. Если поле, у которого есть этот атрибут не заполнить, то при попытке отправить форму браузер отобразит предупреждение, при этом если required полей в форме несколько, то при попытке отправить такую форму браузер покажет предупреждение только для первого незаполненного required поля.

Атрибут disabled - делает группу элементов или конкретный элемент неактивным, не позволяя с ним взаимодействовать и визуально перекрашивает элемент в серый цвет. Применяется для тегов input, textarea, select, option, otpgroup, button, fieldset

Атрибут readonly делает input, textarea недоступным для редактирования.

Атрибут placeholder служит подсказкой для поля ввода input или textarea (показывает, что нужно туда вписать)

Атрибут inputmode позволяет указать альтернативную клавиатуру на мобильных устройствах. Применяется к input и textarea. Значения, принимаемые атрибутом:
- text
- none
- numeric
- decimal
- tel
- email
- search
- url

Атрибут type - строгий inputmode

Autocomplete - автоматическая подставка данных в поле. значений у атрибута всего два - on и off

Autofocus - при открытии страницы взять этот элемент в фокус

Атрибут form (не путать с тегом) - применяется для input, textarea, select, чтобы прикрепить их к определенной форме

minlength иmaxlength - сам понимаешь, что делают, используются в input, textarea, select

size - длина при моношире
pattern - регулярка в инпуте

Spellcheck - проверка правописания. True or False
novalidate - -required поля

rows and columns - теги ширины и высоты для textarea

wrap - для textarea, указывает то, как будет отформатирован текст при отправке на сервер, а именно как будут вести себя значения переноса строк. Значения soft и hard
