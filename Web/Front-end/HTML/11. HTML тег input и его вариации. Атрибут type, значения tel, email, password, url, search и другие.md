 type="email" нужен для обозначения поля ввода адреса электронной почты. Перед отправкой браузер проверит корректность введенного значения, а именно есть ли в нем соответствующий символ "@" и домен после него. На мобильных устройствах при вводе значение в такую вариацию тега input виртуальная клавиатура добавит на панель кнопок символ собачки и точки. 

type="url" нужен для обозначения поля ввода url адреса какого-либо сайта. Браузер проверит валидность ссылки перед отправкой и клава подставит символы для ввода адреса сайта

type="tel" служит для обозначения поля ввода номера телефона, введенное значение не проверяется автоматически, подставится клавиатура с цифрами

type="search" служит для поля ввода поискового запроса, браузер выведет кнопку с крестиком, при нажатии на которую с поля удалится любое значение, крестик можно скрыть с помощью СSS

type="number" предназначен для полей, в которые надо вводить только числовые значения, справа появится стрелочки, благодаря которым можно изменять значение на одну единицу

type="password" служит для поля ввода пароля. Браузер будет скрывать вводимое значение символом точки

у атрибута type есть множество значений для полей ввода дат в разных форматах. При этом под каждый формат будет специальный вид браузерного тултипа, который видоизменять через CSS нельзя. Вот список type="?":
- date - формат ДД.ММ.ГГГГ
- datetime-local - формат ДД.ММ.ГГГГ и время в текущем часовом поясе
- month - формат "Месяц буквами + год"
- week - "Неделя {номер недели}, год"
- time - формат часы:минуты

type="color" служит для выбора пользователем цвета через специальный встроенный браузером компонент, через CSS не повлиять

type="file" использую для поля, при клике на который пользователь может прикрепить к форме файл или даже несколько файлов, если у input есть тег multiple

type="checkbox" превращает тег input в совершенно другого рода компонент - квадрат, при клике на который появляется галочка. Подобного рода компонент всегда используется совместно с тегом label, в котором описывается текст, с которым соглашается пользователь. У тега input и label должны быть теги id и for с одинаковым значениям, чтобы связать эти теги.

Также стоит обратить внимание на атрибут value у тега input, этот текст (value="agreement") служит для того, чтобы сервер после отправки формы распознал выбор пользователя, а если такому input с type="checkbox" добавить атрибут checked, то по умолчанию такой input будет сразу отмечен галочкой, который при желании можно будет снять.

type="radio" - очень похож на checkbox, но служит для выбора одного значения из нескольких предложенных. Для его корректной работы также необходимо связать input и label через атрибуты id и for, но еще требуется указать атрибут name, значение которого должно быть уникальное для всей группы радиокнопок, среди которых пользователь может выбрать одно значение

type="range" выводит ползунок для выбора чисел из заданного диапазона (атрибуты min и max)
