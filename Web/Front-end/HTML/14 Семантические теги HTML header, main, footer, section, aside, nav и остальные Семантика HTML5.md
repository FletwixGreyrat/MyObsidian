
Семантика по фронтенд разработке и верстке в частности - это показательная характеристика качества веб-приложения. Если разметка сайта семантичная, то это дает ощутимую пользу владельцу сайта, так как такой сайт будет лучше продвигаться поисковыми системами, а также сайт будет удобен для большего числа пользователей. Если кратко, семантика - это использование тегов по из назначению.\

У каждого тега есть назначения. При выборе тега для разметки элемента стоит отталкиваться от типа содержимого и стоит пытаться найти среди всех существующих тегов подходящие по роли и смыслу

В html5 добавили несколько важных семантических тегов, которые в современном вебе используются буквально на каждом сайте. Визуально все рассматриваемые в этом видео теги никак не отличаются от нейтрального тега div, ну то есть браузер не добавляет к ним абсолютно никаких стилей

Тег header используется для выделения верхней части страницы, секции или любого другого блока. Как минимум, подобный тег используется для так называемой шапки страницы. В Шапке сайта обычно располагается логотип компании, меню навигации, кнопки авторизации, кнопки поиска и подобные элементы. 

Тег footer служит для выделения нижней части страницы, ее еще называют подвалом, а также для нижней части секции или любого другого блока. В футере сайта обычно размещают логотип, дополнительную навигацию, различные сноски копирайта и подобное

тег main используется для выделения основной части страницы, располагается между шапкой и подвалом, то есть между и хедером и футером, так как хедер и футер сайта это фактически неизменяемые от страницы к странице куски, то для удобной группировки основной части контента как раз используют тег main. Этот тег на странице может быть ровно один.

Тег section используется для выделения независимых функциональных блоков, обычно крупных секционных. Например, каталог товаров, блок с новостями, контактами и тому подобное. Тег внутри себя обязан содержать заголовок, обычно это заголовок второго уровня (h2). Ну и последняя особенность этого тега - section разрешается вкладывать друг в друга. 

Тегa article используется не для статьи, вернее не для такого рода контента, как может показаться по названию. Он прежде всего используется для выделения самодостаточного блока какой-то конкретной сущности, это может быть карточка товара, карточка новости, рекламный баннер, виджет и подобное. Одним из неочевидных правил: если блок в теории можно вынести на другой сайт в качестве рекламного баннера, то такой блок наверняка стоит сделать через тег article

Тег aside предназначен для выделения блока с дополнительным содержимым, обычно подразумевают какую-то боковую колонку на сайте: блок с новостями, фильтр каталога и подобное, однако никаких правил по визуальному положению тега не существует, он не обязательно должен находиться сбоку, главное помнить, что это дополнительное и косвенное содержимое. 

Тег nav предназначен для выделения блоков навигации, на странице таких тегов может быть больше одного, однако увлекаться им не стоит, но как минимум желательно иметь один такой тег в разметке для обозначения основного меню сайта. Обычно это меню со ссылками в шапке

Есть еще один тип меню - breadcrumbs (хлебные крошки) его также советуют оборачивать в nav, это то самое меню навигации, которое располагается во внутренних страницах многостраничных сайтов и представляют из себя цепочек страниц для иерархии сайтов от главной ко внутренней
