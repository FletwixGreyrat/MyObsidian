
Тег blockquote является блочным. Служит для большого блока с цитатой, обычно обернут в тег параграфа.

Цитата без указания источника является плохой с точки зрения информативности и семантики. Указать его можно с помощью атрибута cite или одноименного тега.

Отличаются они тем, что при указании источника через атрибут визуально ничего не отобразится на экране и мы просто увеличим семантику нашей разметки

Тег q - строчный аналог блочного тега blockquote. Используется он для выделения коротких цитат прямо в тексте, например, внутри параграфа. По умолчанию браузер добавит кавычки на границах текста. Вид кавычек отличается в зависимости от указанного атрибута lang
