															
Атрибут class применим ко всем элементам на странице, используется как CSS селектор, но о них позднее

Атрибут id является уникальным идентификатором в рамках одной страницы, используется как селектор, но выступить может также и для якорной ссылки и связывания поле ввода с описанием 

Атрибут title - маленький тултип при наведении на элемент страницы, хорошим тоном является использовать на иконках

Атрибут hidden - скрытие тега. Удобнее делать скрытие на CSS

tabindex - наведение при табуляции. При значении 0 будет самостоятельно определяться браузером, такой подход более предпочтителен. При значении -1 исчезнет из фокусирования

атрибут lang - указание языка содержимого

contenteditable - изменение содержимого тега, принимает значения true и false, без значения - true

spellcheck - проверка правописания, значение тега true и false

style - стиль прямо в html разметке, плохой подход

data-{свой текст} - атрибут пригодится в js, чтобы прочитать из разметки какую-то доп информацию, также используется в качестве селекторов
