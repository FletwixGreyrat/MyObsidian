тег textarea выводит многострочное поле ввода, тег парный. Если записать какой-либо текст в теле тега, то этот текст будет выведен в многострочном поле по умолчанию. Браузер по умолчанию разрешает менять ширину и высоту поля, потянув за правый нижний угол, это поведение можно отключить как для одной оси, так и для двух сразу

тег select используется для вывода выпадающего списка для выбора одного или нескольких заранее готовых вариантов опций, дочерними элементами тега select являются теги option, каждый из которых соответствует определенному варианту ответа. В теге option обязательным атрибутом является атрибут value (значение для сервера).

Для множественного выбора в теге select нужно указать тег multiple.

По умолчанию в одиночном select в качестве ответа выбрана первая опция, если мы хотим сделать выбранной другую опцию, нужно добавить атрибут selected, для пустой опции необходимо добавить в самое начало cелекта пустой тег option, можно добавить текст "не выбрано" или что-то еще по смыслу. Можно пропустить выбор, указав тег required. Поставить запрет на пустую опцию -- value=""

 disabled + selected атрибуты в первой опции лишат пользователя соблазна оставить пустой результат

тег optgroup используется для визуальной группировки нескольких тегов option внутри select. В атрибуте label указывается заголовок группы. В реальной практике тег используется крайне редко, но знать его будет не лишним
