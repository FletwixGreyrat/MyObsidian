
cvg графику в веб разработке можно использовать разными способами. Во-первых, мы можем просто вставить изображение через тег svg. Можно открыть векторное изображение через текстовый редактор, скопировать его параметры и вставить напрямую в html разметку. Эти два способа не взаимозаменяемы, каждый служит для определенной цели. Способ вставки в разметку повышает гибкость разработчика над фотографией, мы можем менять на уровне атрибутов множество параметров, но обычно меняются только цвета.

Если мы хотим как-либо взаимодействовать с векторной графикой, то вставлять такое изображение стоит через специальный тег svg.
