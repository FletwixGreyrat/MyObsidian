
Формы и поля ввода -- главные интерактивные элементы любого вебсайта. Пользователи постояно вводят какие-то данные себе в поля, заполняя анкеты обратной связи, жмут на квадраты-чекбоксы, соглашаются с условиями пользования и т.д

Начнем с тега form. Этим тегом оборачивают группу тегов, с которыми взаимодействуют пользователи, у него есть два важных атрибута: action и method. В значении первого указывают адрес скрипта-обработчика, расположенного на стороне сервера, который обработает нашу форму при ее отправке. В значении method указывается тип http запроса (get, post, put, delete), по умолчанию post. 

тег fieldset служит для визуальной группировки полей ввода в один набор. Браузер по умолчанию задает однопиксельную серую рамку, которую можно убрать через CSS. 

тег legend используется в качестве заголовка внутри тега fieldset, он поместит его вместо линии 

тег label -- тег метки к любому интерактивному тегу поля ввода. Семантически является обязательным, без него по-хорошему не должен существовать ни один интерактивный элемент формы. О том, как он соединяется с полем ввода, мы обсудим далее при разборе конкретных тегов пользовательского взаимодействия.

тег input -- самый главный и многогранно сложный тег для пользовательского взаимодействия. Тег является одиночным. 
У тега input есть атрибут name. Его значение определяет имя элемента формы, которое необходимо серверу для распознавания введенных пользователем данных, когда форма будет отправлена.  Если у поля ввода не заполнен атрибут name, то сервер не увидит данные, которые пользователь ввел в это поле. Атрибут value служит для нескольких целей: в тех инпутах, в которых пользователь может ввести данные с клавиатуры, при указанных в разметке атрибуте value, браузер отобразит содержимое как значение по умолчанию, а для другого рода инпутов атрибут value играет немного другую роль, но об этом позже. Настройка вариации тегов input настраивается с помощью атрибута type (text  по умолчанию)
