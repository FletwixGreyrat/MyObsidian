Псевдоклассы - это специальные селекторы к элементам, которые удовлетворяют определенным условиям. Например, элемент является вторым элементом среди всех своих соседних, или элемент не содержит какой-либо класс, элемент находится в состоянии наведения курсора или фокусировки с клавиатуры. Псевдоклассов существует очень много, больше, чем псевдоэлементов (примерно 60).

Первая группа псевдоклассов - :child. С помощью селекторов этого типа можно получить доступ к элементам по их положению среди своих соседних элементов по их порядковому номеру. Для получения доступа к первому и последнему элементу среди групп однородных элементов используются псевдоклассы :first-child, :last:child. Для остальных используется :nth-child(n), можно также указать ключевые слова odd, even для нечетности и четности по элементам. Аналогический псевдокласс используется для нумерации с конца: nth-last-child(n). При выборке, например, каждого третьего элемента, нужно указать в аргументе псевдокласса 3n. Можно также указать старт элемента, указав (3n + 5), тогда выборка начнется с пятого элемента, и пойдет дальше к 8, 11, 14 и т.д. Для первых нескольких элементов, например, 4, можно указать (-n + 4)

Не всегда можно вспомнить все выборки, поэтому иногда лучше использовать nth-child.better.io.

:only-child позволяет изменять элемент, только если в группе элементов он является единственным из класса

инверсия условия в css. пример :not(:last-child)


Псевдоклассы состояний - это состояния элемента, когда пользователь с ними взаимодействует. В CSS псевдоклассы состояний пишутся как часть селектора в конце и  добавляются к основному селектору элемента.

:hover, отвечает за наведение курсора мыши. С точки зрения ux скажу, что добавляя какие-либо интерактивные элементы, полезно изменить его состояние

:focus отвечает за наведение tab'ом

:disabled делает элемент невозможным для взаимодействия

:checked (for checkbox and radio only)
