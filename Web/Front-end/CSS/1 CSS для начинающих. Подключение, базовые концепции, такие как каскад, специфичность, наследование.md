#### Способы подключения CSS к странице:
- Атрибут style в любом html теге
 Пример:
 ```html
 <p style="color: green; font: 700">Параграф с примененными стилями</p>
```
; - разделитель

- Тег style
Пример:
```html
<style>
 p {
 color: teal
 }
a {
color : hotpink
}
</style>
```
Обычно прописывается в теге head. Теоретически, можно использовать в теге body, но в таком случае разметка будет не совсем корректной. Такой способ указания стилей может показаться удобным, но так делать не рекомендуется. Обычно, разметки в каждом проекте очень много, а стилей еще больше, размещать их в одном файле - архитектурное безобразие.

- Доп файл {filename}.css

Лучшим способом подключения стилей к html является использование отдельного файла с расширением .css

Для подключения файла стилей используется тег link, который размещается внутри тега head, имеет два важных атрибута:
 - rel - тип тега
 - href - ссылка на объект


#### Анатомия CSS-правила

Весь CSS состоит из групп правил. Правило состоит из селектора, свойств и значений

```CSS
p {
    color: teal;
}
```

p - селектор
color - свойство
"teal" - значение


Селекторы - это такие ключи доступа к элементам разметки

ВАЖНО!!! Не забывать ; при написании стиля

Каскад -- это механизм, определяющий порядок применения стилей к элементам. Каждый элемент может иметь несколько правил стилей и именно каскад определяет, какие из них будут применяться, основываясь на приоритетности, специфичности и источнике, также каскад позволяет наследовать свойства от родительских элементов и переопределять их в дочерних
