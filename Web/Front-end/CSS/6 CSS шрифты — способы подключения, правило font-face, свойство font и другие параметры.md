woff2 - самый оптимизированный и легковесных из всех перечисленных, он имеет поддержку браузеров 96%

У каждого шрифта есть несколько вариантов начертания, или вариантов жирности

500 - Medium
600 - SemiBold
700 - Bold (жирный)

некоторых значений не может быть в зависимости от шрифта 

Шрифтов существует огромное количество, каждый шрифт является определенным семейством. Для того чтобы применить к странице какое-то семейство шрифта, нужно воспользоваться свойством font-family


1 вариант подключения шрифта - директива

@font-face {
    font-family: "Roboto";
    src: url("") format("woff2");
    font-weight: 400;
    font-style: normal;
    font-display: swap;
}

штуки внутри называются дескрипторы

2 вариант - директива import

синтаксис достаточно простой

@import url(");

3 вариант - через тэг линк


все шрифты и текст для подлючения можно найти в Google fonts


лучший вариант - скачивать локально, чтобы не нагружать трафик, не скачивать лишнего с сайта гугла, ведь чаще всего наш днс сервер справится с загрузкой шрифта быстрее, плюс не стоит забывать про тот факт, что сайт google fonts может лечь, тогда и у нас будут проблемы со шрифтом, поэтому все локальное - все крутое

Чаще всего достаточно трудно найти подходящий шрифт в woff2, тогда можно обратиться в сторонние сервисы, например в transfonter.org


Теперь пробежимся по css свойствам, относящимся к шрифтам

свойство font - обобщенное свойство для параметров шрифта, в нем одной строкой можно указать сразу несколько параметров, это достаточно мудреный способ, ведь использовать все это нужно в правильном порядке, в противном случае что-то может не работать, обычно так не делают, да и  не используют все свойства. 

Свойства, которые действительно пригодятся в работе:
- font-family  - задается семейтсво шрифта, если имя шрифта состоит из нескольких слов, то нужно обернуть в кавычки, можно и нужно указывать несколько значений шрифтов через запятую (если не загрузился первый шрифт, то загрузится второй и так далее)
- font-weight - задает жирность текста (как и писал выше)
- font-size - размер шрифта. пока будем записывать в пикселях
- line-height - задает межстрочный интервал (интерлиньяж), значение можно указать в пикселях и процентах или коэффициентах (1.5 и т.д)
Работая с макетами, часто указывается line-heightв пикселях, но лучше прописать его в коэффициенте (line-height / font-size и округлить до двух знаков после запятой, после чего вписать это в line-height). так нужно, чтобы верстка всегда подстраивалась под вас, меняя font-size
