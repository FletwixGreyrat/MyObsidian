	
	
	У некоторых html тегов есть стили по умолчанию, которые им присваивает браузер. Например, у тегов заголовков, списков и параграфа есть внешний вертикальный отступы margin, у ul и ol есть padding слева и справа
	
	Различные браузеры стилизуют те или иные элементы по-разному
	
	Для начала напрашивается как минимум удаление свойств в ноль
	
	```css
	* {
	margin: 0;
	padding: 0;
	border: none;
	list-style: none;
	}
	```
	
	Но этот подход - не самое чистое решение, поскольку выбирая по единому селектору * многие из свойств аннулируются у тех тегов, которые в этом не нуждаются. У большинства тэгов нет ни внутренних, ни внешних отступов
