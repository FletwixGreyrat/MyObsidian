свойство transform отвечает за трансформацию: смещение, масштабирование, поворачивание или искажение, по умолчанию значение у свойства none.

В качестве значений transform принимает различные функции

Первая функция translateX() - смещает элемент по горизонтали

translateY - по вертикали

translate - шорткат

scaleX - отвечает за масштабирование по оси X
scaleY - по оси Y
scale - шорткат

rotate - отвечает за поворот элемента, по умолчанию значение 0deg, то есть не повернуто

scewX - искажение элемента по горизонтали (в градусах)
scewY - по вертикали
scew - шорткат

значения свойства можно указывать через пробел

теперь для основных функций есть отдельные свойства

translate, scale, rotate (одно значение только для горизонтали)



свойство transform-origin - применяется совместно со свойствами трансформации и задает положение, относительно которого они применяются. По умолчанию у transform-origin значение center


чтобы добавить плавности анимациям можно добавить свойство transition, это свойство включает в себя другие подсвойства:
- transition-property - имя свойства, на которое хотим влиять, либо ключевое слово all, если мы хотим добавить плавности всем свойствам
- transition-duration - это длительность перехода
- transition-timing-function - функция скорости изменения свойства
- transition-delay - длительность задержки перед началом изменения свойств

Частая ошибка новичков - задавать transition в :hover, однако работать такое будет некорректно


transition может также работать не только с  transform, а с color, background-color, border-color, outline-color, box-shadow, filter, top, right, left, bottom и другие


Рассмотрим свойства функции перехода transition-timing-function. В CSS иногда добавляют новые, однако используются только основные:
- ease
- ease-in
- ease-out
- ease-in-out
- linear
- cubic-bezier
