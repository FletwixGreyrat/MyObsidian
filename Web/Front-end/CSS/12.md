
В первую очередь разберемся с термином flexbox-layout

flex - гибкий
flexbox layout - гибкая сетка

display: flex - делает из элемента flex-контейнер. У flex контейнера есть оси - основная и поперечная. Основная ось - это та, вдоль которой располагаются дочерние  элементы, по умолчанию это горизонтальная ось 

По умолчанию flex-контейнер как бы блочный 

По умолчанию контейнер располагает элементы по горизонтали, его основная ось идет слева направо, а побочная сверху вниз, мы можем менять оси местами и их направления через свойства flex-direction. 

значения flex-direction:
- row
- column
- row-reverse
- column-reverse

Дочерние элементы flex-контейнера будут стараться уместиться в один ряд, даже если у них заданы размеры, которые физически не должны позволить влезть им всем на одну строку. Это поведение можно и иногда нужно менять, для этого есть свойство flex-wrap. По умолчанию значение этого свойства nowrap, оно запрещает дочерним элементам контейнера переноситься при переполнении

Значение wrap делает ровно наоборот. При переполнении элементы не будут мешать друг другу и ужиматься, а переноситься на следующую строку. 

Еще одно значение этого свойства - wrap-reverse. Это крайне непопулярное значение, при котором элементы будут располагаться снизу вверх.

Для двух последних свойств есть обобщенное свойство flex-flow. Два ключевых слова перечисляются между собой в произвольном порядке. 

flex-grow - свойство, которое применяется к контейнерам и указывает, может ли элемент растягиваться и в каких пропорциях относительно соседних элементов. Растягиваться элемент может, даже если ему заданы конкретные размеры. В качестве значения свойство принимает число от 0 и выше, по умолчанию значение равно нулю, в таком случае элемент ведет себя стандартно и не пытается растянуться. Если прописать для всех flex-элементов flex-grow: 1, то эти элементы равномерно растянутся и займут все доступное им пространство в контейнере. Со значением 2 элемент будет стараться занять в два раза больше места, чем другие контейнеры.

Ключевое слово - стараться, не стоит надеяться на пропорциональное увеличение такого элемента в два раза. на реальной практике почти всегда используется flex-grow: 1. 

fllex-shrink - полная противоположность свойству flex-grow, только пропорции для уменьшения. Чаще всего будет  нужно flex-grow: 0, чтобы отображать реальные размеры элемента

еще одно свойство, влияющее на flex-элементы - flex-basis указывает элементу размер до того как будет распределено свободное место родительского flex-контейнера за счет свойство flex-grow у дочерних элементов. flex-basis всегда будет приоритетней. Значение по умолчанию - auto, то есть будет смотреть на размеры flex-элемента, указанные через width и height, а так же на flex-grow. Значения могут быть заданы в любых единицах измерения

из-за особенностей flex-лэйаута, элементы внутри контейнера могут занимать неочевидное пространство за счет своих нестандартных параметров (последние три)

чтобы удобно управлять всеми тремя свойствами есть обобщенное свойство-шорткат flex (grow; shrink, basis). Значения по умолчанию 0;1;auto.

свойство order: применяется к flex-элементам и меняет их визуальный порядок в контейнере, по умолчанию значение 0 (порядок автоматический). Чтобы сделать элемент визуально последним, нужно указать order: 1, а чтобы первым: order; -1. Числа могут быть отрицательные и положительные.

Злоупотреблять свойством order не стоит, особенно не стоит задавать это значение каждому элементу контейнера. В реальной практике обычно применяют значение 1 и -1. 

Далее рассмотрим свойство выравнивания, что очень часто используется в верстке не flex'ах. Для выравнивания используется свойство justify-content. Значений у этого свойства довольно много, но мы рассмотрим только то, что действительно используется на практике. 

- flex-start: элементы внутри контейнера будут прижиматься к началу основной оси, формально это значение по умолчанию.
- flex-end: делает ровно противоположное
- center: располагает элементы по центру
- space-between: первые и последние элементы внутри контейнера располагаются строго по его краям, а остальные выстраиваются равномерно с одинаковыми отступами друг от друга. 
- space-around: делает так, что свободное пространство контейнера будет поделено на столько частей, сколько в нем находится элементов, в начале и конце по половине от этого размера
-  space-evenly: похож на предыдущее, но все расстояние будет одинаковым

следующее свойство выравнивания - align-items. Выравнивает элементы внутри контейнера по побочной оси, значений сильно меньше, чем у предыдущего свойства.

- strech (по умолчанию) - элементы будут растягиваться вдоль побочной оси так, чтобы заполнить всю высоту.
- start (flex-start) - располагает элементы в самом начале побочной оси
- end (flex-end) - располагает элементы в самом конце побочной оси
- center - располагает по центру
- baseline - все элементы будут выровнены по базовой линии текста

align-content: можно распределить свободное пространство между рядами элементов по поперечной оси, значение по умолчанию stretch. остальные работают похожим образом

- flex-start
- flex-end
- center
- space-between
- space around
- space-evenly 
в реальной практике это свойство применяется редко, но будет не лишним

свойство gap - c помощью этого свойства можно задавать отступы между элементами по вертикали и горизонтали, в значении через пробел указываются промежутки между элементами сначала по горизонтали, затем по вертикали.

свойство gap - шорткат для свойств row-gap column-gap.
