
свойство background - это обобщенное свойство, которое позволяет задать одной строкой множество параметров фона: фоновый цвет, изображение, режим повторений изображения, позиций изображения, размер изображения, режим фона при прокрутке и область применения (последние два параметра применяются чрезвычайно редко). Параметры можно прописывать практически в любом порядке. Единственное правило - параметры позиций изображения и размеры идут строго друг за другом и разделяются с помощью слэша, а теперь рассмотрим все подсвойства в подробностях


background-color - задает элементу фоновый цвет, в качестве значения можно указать все те форматы, что и в прошлом конспекте

background-image - задает элементу фоновое изображение или градиент. 
```css
background-image: url("./cat.jpg")
```

background-repeat - задает режим повторения изображения. Можно указать два значения : одно отвечает за ось x, другое за ось y, если один элемент, то за обе оси.  

background-position - управляет позиционированием изображения. Значение по умолчанию - 0, 0 (горизонталь и вертикаль, одно число - онли горизонталь), обычно значения указывают в пикселях или процентах

background-size - отвечает за размеры элемента, значение по умолчанию - auto, при этом размеры будут как у оригинального файла изображения

background-attachment - задает правила фона при скролле, значение по умолчанию - scroll. Фон жестко привязан к элементу и при скролле странице ничего особенного с фоном страницы не происходит. Значение fixed будет зафиксировано относительно родительского прокручиваемого элемента. При значении local фон будет прокручиваться в зависимости от поведения элемента. 

background-clip - определяет в какой области блочной модели элемента будет находиться фон, изображение и цвет, значений у этого свойства несколько. border-box - значение по умолчанию, фон займет всю область элемента, в том числе залезет под рамку элемента. padding-box - фон займет всю область, но не будет залезать под рамку. Значение content-box - фон займет только контентную область, то есть не будет залезать на рамку и на область от внутреннего отступа padding. значение text - фон будет применен к текстовому содержимому элемента. Это значение заработает, только если у свойства цвета текста color задано значение transparent (прозрачность), но в хроме не работает, нужно продублировать background-clip c указанием в начале имени вендорного префикса -webkit- (об этом позже). 

Градиенты
Градиенты задаются фоном к элементу через свойство background-image. в CSS существует три вида градиентов - линейный, радиальный и конический. Каждому виду градиента соответствует функция: linear-gradient, radial-gradient, conic-gradient. у каждой из функций есть дополнительная с префиксом repeating-, для которой для каждого цвета нужно задавать размеры, и таким образом для градиента будет задан повторяющийся паттерн.

Градиенты - не самая простая тема, да и глубокое их познание может не пригодиться вовсе, поэтому подробно рассмотрим лишь самые популярный вид градиента - линейный. Стандартный синтаксис функции linear-gradient простой, мы просто перечисляем в скобках цвета, минимум два, пропорции занимаемых цветов будут равны

направление градиента можно менять, для этого в самом начале функции указать угол в градусах (от 0 до 360, единица измерения deg), по умолчанию 180 градусов (сверху вниз). Запись можно вести и в turn'ах (1 turn - 360 градусов).

направление градиента можно также задавать через ключевые слова, их всего 8:
- to top
- to top right
- to right
- to bottom
- to bottom left
- to left
- to left top

СЛОЖНО
В градиенте можно управлять точками перехода цвета, а именно задать в любой единице измерения граничные значения цвету сразу после него, через пробел. Первое - при котором плавно закончится переход из предыдущего цвета, а второе - с которого плавно начется переход в следующий цвет. Если конченая точка предыдущего цвета и начальная точка следующего цвета совпадает, то переход между цветами будет мгновенный, без плавности. 

Обычно градиенты не пишутся вручную, а берутся из, например, cssgradient.io


Новички и не только часто задают цвет через обобщенное свойство color, например, background: red. Смысла в такой записи мало. Если для указания одного лишь цвета мы используем общее свойство background, то браузер переопределит все подсвойства, которые могли быть заданы ранее. Чтобы избежать лишних переопределений, для задания лишь одного подсвойства лучше изменять его точечно. Совет относится и к другим свойствам (font, margin, padding и подобным)
