Анимации в css начинаются с объявления групп правил ключевых кадров, которые описываются в рамках так называемой директивы @keyframes.

Ключевые кадры - это понятие из мира видеомонтажа, каждый кадр имеет определенное расстояние в конкретную единицу времени. В CSS ключевые кадры описывают значения свойств в определенный промежуток времени выполнения анимаций.

Сначала пишем имя директивы, начиная с символа @, затем имя анимации, оно может быть любым. Внутри в фигурных скобках пишутся группы правил, каждое из которых отвечает за определенный момент времени выполнения анимации. Название такой группы анимаций могут быть либо ключевым словом from и to, что соответствует начальному или конечному кадру анимации. Можно так же задать значение от 0 до 100 в процентах. Начальный ключевой кадр мы можем и не задавать вовсе, тогда возьмется начальное состояние элемента. При желании мы можем указывать сколько угодно ключевых кадров с привязкой к моменту от 0 до 100 процентов

для применения анимации нужно указать свойство animation со значением имени анимации и через пробел доительность этой анимации. Анимация запускается не сразу, а после того, как загрузится весь html и css

Анимации можно настроить очень гибко, благодаря подсвойствам

animation-name - имя анимации
animation-duration - длительность анимации 
animation-delay - задержка перед началом анимации
animation-iteration-count - количество прогонов анимации. В значении можно указать ключевое слово infinite, для бесконечной анимации. 

Как и у переходов, у анимации можно задать скорость выполнения анимации, делается это через свойство animation-timing-function

animation-direction - свойство, которое мы задаем, чтобы сказать, должна ли анимация выполняться в обратном порядке. Значение по умолчанию normal,
При значении reverse ключевые кадры будут идти от конца до начала. Значение alternate будет каждый четный прогон делать обратным. И значение alternate-reverse будет каждый нечетный прогон делать обратным

animation-play-state - позволяет ставить выполнение анимации на паузу, значение по умолчанию running, а второе - paused
