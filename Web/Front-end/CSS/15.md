Гриды - это современная фича CSS для верстки элементов, позволяющая парой движений реализовывать сложные на первый взгляд сетки, которые ранее требовали больше кода. Флексы и гриды решают те же самые задачи, но имеют разные подходы. Гриды - более современная технология CSS, однако не нужно их противопоставлять и считать, что они взаимозаменяемы. 

Грид контейнер - это элемент, к которому применено grid или inline-grid. 

Грид линии - это горизонтальные и вертикальные разделительные линии, формирующие структуру лэйаута. Чтобы лучше понять грид сетки, советую использовать dev tools и включать отображение контейнера

Грид ячейка - это пространство между соседствующими грид линиями.

Грид полоса - это пространство, ограниченное двумя соседними горизонтальными или двумя горизонтальными линиями

Грид область - это пространство, ограниченное четырьмя грид линиями

Когда мы задаем элементу display: grid, элемент становится grid-контейнером, а на элементы будут действовать правила грид лэйаута, по умолчанию грид блочный


Второе по важности свойство грид лэйаута, без которого сетка не получится - grid-template-columns. С помощью этого свойства можно задать количество и размер колонок, на которое будет поделено пространство. Если количество элементов будет больше, чем заданное количество колонок, то элементы будут переноситься на следующую строку, по аналогии с flex-wrap во флексах. Форматов у свойства много:
- Можно перечислить размер каждой из колонок (Например, auto, auto, auto). То есть ширина каждого элемента будет вычислена автоматически, в зависимости от ширины внутреннего содержимого
- использовать абсолютные единицы измерения (проценты, вьюпорт единицы)
- между значениями колонок перед ним можно прописать в квадратных скобках имя каждой грид линии. Подобное именование может быть полезно в сложных грид сетках, чтобы банально повысить удобство чтения кода.
- использовать функцию repeat (Например, repeat(3, 150px))

Для грид лэйаута также существует особенная единица измерения fr (от английского fraction - дробь, доля, часть). С ее помощью мы показываем, на сколько равных частей будет поделено пространство

Можно также задать ширину через функцию minmax(200px, 35%). При таком значении браузер будет самостоятельно регулировать ширину первого столбца, который будет варьироваться от 200 пикселей до 35 от ширины грид контейнера

помимо указания количества и размеров колонок грид контейнера, можно явно указать и высоту строк через grid-template-rows. Форматы этого свойства аналогичны grid-template-columns

крайне редко может возникнуть ситуация, когда необходимо задать конкретную высоту строк грид контейнера, для этого можно воспользоваться свойством grid-auto-rows. Можно указывать несколько значений, тогда они будут применяться циклично 

Аналогичное свойство есть и для колонок - grid-auto-columns. Работать оно будет только в тандеме со свойством grid-auto-flow со значением column, которое говорит о том, что элементы внутри контейнера не должны переноситься автоматически на новые строки, чтобы они умещались в одну строку по указанному grid-auto-columns паттерну.


grid-template-areas позволяет указать шаблон сетки грид контейнера. В значении свойства через пробел в кавычках указываются строки. В каждой строке через пробел перечисляются названия зон, эти названия могут быть любыми, можно даже использовать эмодзи, а если нужно указать имя пустой ячейке, то нужно использовать символ точки. Важно указывать имена для каждой ячейки, иначе свойство работать не будет. После задания шаблона нужно распределить элементы по областям, делается это через свойство grid-area, а значения применяются из grid-template-areas.

row-gap, column-gap, gap также работают  с грид лэйаутами

На гриды также будут действовать свойства justify-content и align-items, отвечающие за выравнивание по горизонтали и вертикали. По умолчанию значения обоих свойств - norman

- start
- end
- center
- stretch
- space-between
- space-around
- space-evenly

с помощью свойства align-items мы можем выровнять элементы по вертикальной оси, для этого свойства возможны следующие значения
- normal
- start
- end
- center
- stretch

Для двух свойств есть обобщенное свойство шорткат place-items, которое позволяет задать значение выравнивания по вертикали и по горизонтали. Если оба значения совпадают, то можно сократить до одного ключевого слова

Поговорим про позиционирование грид элементов. У каждого грид контейнера у которого как минимум заданы колонки есть грид линии, их можно увидеть через dev tools

допустим нам нужно сделать одну ячейку на два столбца и две строки, тогда зададим через grid-column-start начало размера по горизонтали, затем grid-column-end, по аналогии grid-row-start и grid-row-end. Шорткатом можно указать горизонталь и вертикаль отдельно (например, grid-column: 2 / 4). Вместо чисел можно использовать имена элементов

Также в значении свойств grid-column и grid-row можно использовать ключевое слово span (не путать с тэгом). Если написать, например, grid-column: span 2; , то грид элемент займет ровно два столбца, при этом браузер автоматически подберет ему наилучшую позицию в сетке грид контейнера

Есть еще один необычный, но безумно полезный формат значения для свойства grid-column. Допустим, у нас есть трехколоночная сетка и нам нужно растянуть один из элементов на всю ширину столбца. Задать такое можно через grid-column: 1 / 4 или через ключевое слово span, но в обоих случаях мы должны учитывать количество колонок в контейнере. Однако можно использовать хитрое значение  -1 / 1, что автоматически растянет элемент на все колонки, независимо от их количества

свойство order также действует на грид элементы, однако не стоит злоупотреблять, а использовать -1 и 1
