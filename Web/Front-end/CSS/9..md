
border - задает элементу рамку, это свойство-шорткат (border-width, border-style, border-color)

свойство border задает рамку по всем границам элемента, но если нужна с конкретной стороны, то на этот случай есть -left, -right, -top, -bottom, -block (сверху и снизу), -inline (слева и справа)

для задания ширины рамки используется свойство border-width, значение можно указать в пикселях, емах, рэмах и вьюпорт единицах, но не в процентах. Для этого свойства существуют ключевые слова thin и thick (не популярно). Можно указать от одного до четырех значений ширины, распределяться все будет так же, как в margin и padding.

border-style - задает стиль рамки.  У этого свойства существует около десятка ключевых слов:
- none
- solid - сплошная линия
- dashed - короткие черточки
- dotted - точки
- double - двойная рамка с небольшим отступом между линиями
- groove
- ridge
- inset
- outset
Рассказывать о разнице между последними четырьмя сложно, все они - рамки с тенями, отличается лишь угол, на который падает тень.

border-style тоже можно прописать для отдельной стороны через -right- -left- и прочее

border-color - цвет рамки, можно указать от одного до четырех значений. Можно прописать для отдельной стороны через -right- -left- и прочее

Рамка border по умолчанию не включена в размеры элемента, заданные через width и height. Если указать box-sizing: border-box, то размеры будут включены в указанную ширину и высоту

outline - задает обводку элемента, но не влияет на его фактические размеры. Это свойство шорткат (outline-width, outline-style, outline-color). Обводку нельзя задать для одной или нескольких сторон, она применяется со всех сторон. Но есть у него свойство, которого нет у border - outline-offset. Оно задает смещение обводки относительно краев элемента, можно указывать положительные и отрицательные значения. 

border-radius - закругление элемента. Не имеет ничего общего с border, кроме названия, значение можно указать в любых единицах измерения, но обычно в пикселях и процентах. Можно перечислить до четырех элементов. Конфигурировать красивые фигуры можно на сайте 9elements.github.io/fancy-border-radius.

Поговорим о связи border-radius и outline, года 4 назад закругления не действовали на обводку, поэтому в старых курсах, учебниках и гайдах советуют не использовать их вместе, теперь же нет смысла опасаться связи outline и border-radius

для задания тени существует свойство box-shadow. Вариаций использования несколько:
- Если задать два значения (можно задавать как положительные, так и отрицательные), то под элементом появится черная тень, смещенная на x значений вправо и на y значений вниз

Смещение по осям можно указывать в любых единицах измерения, кроме процентов, однако чаще всего используют пиксели

 - Если добавить третье значение, то оно будет отвечать за радиус размытия (только положительное значение, можно использовать любые единицы измерения, кроме процентов)
- Если добавить четвертое значение, то оно будет отвечать за радиус распространения (грубо говоря, за размеры этой тени). Это значение может быть отрицательным, тогда тень за элементом будет меньше чем фактические размеры элемента
- Пятым элементом можно указать цвет тени

Для box-shadow есть также специальное свойство inset, которое при добавлении к свойству меняет положение тени с внешней на внутреннюю. Через запятую в свойстве можно указывать несколько теней 

filter - с помощью него можно наложить на элемент множество фильтров, как в популярных фоторедакторах.
