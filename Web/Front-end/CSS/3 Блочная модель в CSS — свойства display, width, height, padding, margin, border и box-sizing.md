
Блочная модель в CSS - это алгоритм расчета размеров каждого отдельно взятого элемента страницы. Схему блочной модели можно посмотреть у любого элемента через инструмент браузерного разработчика.

Блочная модель - это совокупность CSS свойств, влияющих на размер элемента. С этим свойствам относятся:
- width - ширина
- height - высота
- padding - внутренние отступы от содержимого (от контента до краев элемента)
- margin - внешние отступы вокруг элемента
- border - рамка, идущая по краю элемента

Свойства ширины и высоты (width и height) задают размеры контентной области элемента. Контентная область - внутреннее пространство, отведенное под то, что мы поместили внутрь элемента.

У каждого элемента есть параметр типа отображения, это свойство display. У тега div в значении display по умолчанию это блок (display block), мы можем явно указать это в display правиле, но в данном случае это необязательно. Тип отображения "block" говорит о том, что элемент блочный и если мы не задали конкретное значение ширины в свойстве width, то элемент будет занимать всю доступную ему ширину, а вот высота элемента по умолчанию всегда будет подстраиваться под содержимое, под внутренний контент

Если же мы зададим блоку конкретные размеры, свойства width и height, то мы можем увидеть, как изменятся границы элемента. Важное отступление: задавать элементам фиксированное значение высоты и ширины - это плохая практика, если у элемента заданы конкретные размеры, то мы берем на себя ответственность за то, что контент внутри блока никогда не поменяется, а гарантировать это мы не можем, да и не должны

Помимо блочного типа отображения есть еще и строчный. Рассмотрим тег span, по умолчанию он строчный,  то есть у него значение свойства display по умолчанию это inline. Указывать это правило явно в CSS необязательно, тип отображения inline говорит о том, что элемент строчный и его ширина будет равна ширине его внутреннего содержимого, а высота как и у блочного равна высоте внутреннего контента, получается, что блочный и строчный элемент имеет размеры как у его внутреннего содержимого.

Строчным инлайн элементам нельзя задавать ширину и высоту, это просто напросто не сработает, а


Еще одно свойство display - это inline-flex. Такое значение делает элемент блочно-строчным. Отличия: ему можно прописать width и height

У свойства display есть еще одно очень интересное значение - none, оно полностью скрывает элемент со страницы, несмотря на то, что в разметке данный элемент будет присутствовать. Подобный элемент сокрытия элемента применяется очень часто. Информация на будущее: свойство display не анимируется, то есть плавное появление элемента через display none не получится, для этого есть другие механики. 

Свойство padding - задает внутренние отступы. По умолчанию в контексте разговора о блочной модели внутренние отступы от padding прибавляются к высоте и ширине элемента 

Свойство border - добавляет элементу рамку. Синтаксис свойства следующий: ширина рамки, тип линии и ее цвет. Параметры разделяются пробелом и их можно писать в любом порядке. Рамка, как и внутренние отступы, по умолчанию влияют на размеры элемента. Теперь итоговая фактическая ширина элемента.

Свойство margin - задает внешние отступы, они не прибавляются к фактическим размерам элемента, но являются частью блочной модели и влияют на то, сколько места на странице займет элемент, чтобы было проще понять это свойство, margin толкает все вокруг этого элемента на указанное значение.

Свойство box-sizing - меняет формулу расчета фактической ширины и высоты элемента, делает так, что элемент будет иметь размеры ровно такие же, какие и заданы в его значениях width и height и ни padding, ни border не будут увеличивать размеры элементов, так как они будут включены в формулу расчета фактических размеров. Значений у свойства два - content-box (по умолчанию), border-box
