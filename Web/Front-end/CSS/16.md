свойство overflow -  определяет правила того, как будет вести себя блочный элемент, если его содержимое не влезает в его размеры, значение по умолчанию - visible. Другое его значение hidden скрывает все, что выпирает за пределы границ элемента, это самое популярное значение свойства. Следующее значение scroll, выпирающая часть элемента скрывается, однако у блока появляется прокрутка, позволяющая проскроллить и увидеть все внутреннее содержимое. Следующее значение - auto, действует как и scroll, но прокрутка будет появляться только в тех случаях, когда содержимое блока действительно выпирает за его пределы. Значение clip : оно относительно новое, его поддержка браузерами на данный момент чуть больше 80%, применив это значение к элементу, поведение будет похоже на hidden, но есть небольшая разница, которую рассмотрим на примере. 

В свойстве overflow обычно устанавливается одно значение для x и y, однако есть отдельные свойства overflow-x и overflow-y


Opacity - управляет прозрачностью элемента, значением этого свойства может быть число от 0 до 1, а так же дробные значения и проценты. Однако с ним можно взаимодействовать.

Если нужно отключить взаимодействие, то можно использовать свойство visibility (hidden, visible)


clip-path - с его помощью можно обрезать элемент по определенной форме, по умолчанию значение none

- circle(50% at 50% 50%)
- ellipse(50% 50%) (обяз 2 py)
- polygon()
- path
- url
