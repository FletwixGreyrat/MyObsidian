
Селектор по тегу - самый простой селектор, выбирает все теги на странице по его названию.

Селектор по классу - самый частый в использовании. Работает прописыванию атрибута class элементу. Значение class - селектор .{значение класса}. Классов для элементов можно прописать сколько угодно через пробел

Селектор по id. Работает так же, как и селектор по классу, только прописывается #{значение атрибута id}. Отличаются они в уникальности. Значение атрибута id может встречаться лишь раз, а еще нельзя прописать айди через пробел

Селектор по атрибуту. Записывается в файле стилей как  [{имя}="{значение}"] или [{имя}]

[{имя}*={значение}] - аналог оператора in

[{имя}^={значение}] - аналог функции startswith

[{имя}$={значение}] - аналог функции endswith

[{имя}~={значение}] - аналог оператора in, но умнее, смотрит на пробелы

[{имя}|={значение}] - проверка на равенство, или на startswith={значение}-

[{имя}{что-нибудь необязательно}={значение} i] - i игнорирует регистр, также допустимо I. Важно: с кириллицей работать не будет 

\* - универсальный селектор, позволяет выбрать все элементы на странице

{селектор 1},
{селектор 2},
{селектор 3} {

} -  множественный стиль


.{селектор 1}.{селектор 2} - применения стиля к элементу, со всеми указанными значениями атрибута class

{элемент 1} > {элемент 2} - прямой дочерний элемент

{элемент 1} + {элемент 2} - следующий в разметке с таким же уровнем вложенности

{элемент 1} ~ {элемент 2} - все следующие в разметке с таким же уровнем вложенности
