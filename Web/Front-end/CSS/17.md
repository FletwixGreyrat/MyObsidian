
cursor: позволяет менять внешний вид курсора при использовании на устройстве мыши. Это свойство можно применить ко всей странице или к определенному элементу, тогда курсор будет меняться только при наведении на этот элемент. Значений у свойства множество, рассмотрим самые популярные. По умолчанию у курсора значение auto, браузер сам будет решать, какого вида курсор отобразить. Для большинства элементов это стандартная стрелка, а для ссылок это рука с указательным пальцем, для полей ввода - вертикальная черта. Теперь перейдем к нестандартным значениям свойства cursor.

Если указать значение none, то при наведении на такой элемент курсор не будет виден вовсе.

Значение default - стандартный курсор, стандартная стрелка
text - вертикальная черта
pointer - рука

зачастую последнее свойство применяют ко всем кнопкам, однако так делать не рекомендуется, это некорректный ux. 

У свойства cursor есть еще множество значений

user-select - определяет то, можно ли выделить текст в элементе, у этого свойства есть пять значений, но рассматривать все нет смысла, разберем только самые важные

auto - по умолчанию, браузер сам определит правила выделения. В большинстве случаев текст может быть выделен

Значение none отключает эту возможность

pointer-events - отвечает за то, может ли пользователь нажимать на элемент, по умолчанию значение авто, еще одно значение - нан (устал языки менять)

resize - указывает правила того, как можно изменять размер элемента с помощью манипуляций перетаскивания правого нижнего угла. Применяется зачастую к элементу text-area, однако его можно также применить к элементу, у которого задан нестандартный oferflow. Значение по умолчанию у большинства элементов none

У textarea свойство со значением both, позволяет изменять размер в обе стороны

еще два значения:

horizontal
vertical

говорят сами за себя

scroll-behavior - определяет то, как будет вести себя анимация скролла при нажатии на якорную ссылку, или же после применения программного скролла через джаваскрипт

значение по умолчанию - auto
за прокрутку всей страницы отвечает тэг html

еще одно значение - smooth, что делает прокрутку плавной
