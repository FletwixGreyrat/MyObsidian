# 1_1_Введение_понятие_тега,_анатомия_тега,_поток_документа,_вложенность
 - HyperText Markup Language, язык гипертекстовой разметки

HTML используется для создания разметки веб страницы и ее структуры, которая состоит из заголовков, текста, фото, ссылок и многих других элементов. Каждый из таких элементов называется тегом. Теги определяют значение контента и его базовый внешний вид. Почему "базовый"? Потому что каждый браузер стилизует теги по-своему. Для полного контроля этих стилей используется CSS, но о нем позже

Рассмотрим анатомию тега. Большинство HTML тегов парные, такие как p, h1, и другие

```html
<p>Параграф с текстом</p>
```

Существуют также одиночные теги, такие как input. Синтаксис одиночных тегов бывает двух видов

```html
<input>
<input />
```
Оба выполняют одинаковую функцию, но писать как во втором варианте - хороший тон, потому тег что помогает заметить себя при беглом чтении разметки.
	
Потоки - важная концепция HTML. Потоки в верстке - это последовательность тегов и контента, которые отображаются на странице. Текст разметки читается сверху вниз и слева направо

Атрибут - дополнительное свойство тега

Пример кода с объяснением каждой строки

```html
<!doctype html>

<html lang="ru">

<head>

<meta charset="UTF-8" />

<meta name="description" content="Описание страницы" />

<meta

name="keywords"

content="1, 2, 3"

/>

<meta name="viewport" content="width=device-width,inital-scale=1" />

<title>Документ</title>

  

</head>

<body>\

Здесь будет весь контент страница

</body>

</html>
```

doctype в начале документа сообщает браузеру, в каком режиме работать со страницей. Раньше синтаксис написания doctype был длинный и слегка запутанный, однако на данный момент есть лишь один актуальный вариант короткой записи. Той, что используется в коде выше. Поэтому нет смысла глубоко углубляться в детали. Важно лишь не забывать писать данную строку в каждом html файле (в самом начале)

тег html - корневой элемент документа, в котором находится все содержимое страницы. Он открывается на второй строчке данного кода, а закрывается на последней. Также у тега html мы видим атрибут lang со значением "ru". Он говорит браузеру о языке текста, который будет наполнять содержимое тега, а в случае с тегом html содержимым является весь контент страницы. Следовательно, атрибут действует буквально на всю страницу. Обычно для русскоязычной страницы значение атрибута lang указывают "ru", для английской - "en" и т.д

тег head содержит сервисную информацию о странице, например, метаданные, иконку и заголовок вкладки браузера, ссылки подключения файлов стилей, скриптов и т.д. 

тег meta является одиночным тэгом, то есть не имеет закрывающую пару, предназначен для указания различных метаданных, например, информацию о кодировке сайта, данные для поисковых систем в роде описания страницы и ключевых слов, параметр окна просмотра. Данные эти необходимы для корректной работы адаптации сайта под ширины магнитных устройств через CSS. Вариаций тега meta великое множество, однако помнить их все не нужно. Из обязательных, минимально необходимых, можно выделить указание кодировки и meta с параметрами viewport

тег title дает название текущей странице, которая будет отображаться во вкладке браузера. 

тег body содержит весь контент страницы, который фактически будет отображаться в браузере. Важно помнить, что такой тег в коде страницы может быть в коде ровно один (Как и тег head)



# 1_2_Блочные_и_строчные_теги_в_HTML_Теги_div_и_span


Большинство html тегов можно разделить на две категории - блочные и строчные.

Блочные теги - теги, создающие блоки, которые занимают всю доступную им ширину

Строчные теги - теги, создающие элементы внутри блоков и занимают они ширину ширину, равную их внутреннему содержимому

Рассмотрим пример. У нас есть блочный тег p - тег параграфа с текстом внутри. Часть внутреннего текста обернута в тег b, придающий тексту жирность (<b>bold - жирный</b>). 

<b>Важное правило!!!</b> Блочные конструкции могут быть вложены только в блочные конструкции 

Чтобы понять, каким является тег, можно воспользоваться сайтом MDN. К слову, к этому ресурсу нам еще предстоит обращаться

Прежде чем изучать html теги, важно уметь отвечать себе на вопрос "почему я должен использовать именно этот тег, а не какой-либо другой?". Тегов в html более ста, заучивать их все не нужно, достаточно ознакомиться с основными, чтобы в большинстве ситуаций иметь представление, какой тег подходит для определенных элементов пользовательского интерфейса

Когда мы говорим, что каждый тег должен использоваться по его назначению, это называется семантикой. Семантической разметкой называют html код, где все теги подобраны максимально гармонично и по смыслу.

Итак, у каждого тега есть назначение. Например, тег h1 предназначен для главного заголовка страницы, а тег button - для кнопок. У каждого тега есть конкретная роль, которая подходит под конкретный случай. А что делать, если под наш случай не подходит никакой тег? В HTML для таких целей существует два тега с нейтральными ролями - это теги div и span. 

div - блочный тег, то есть занимает всю доступную ему ширину, а span - строчный, занимает ровно столько места, сколько в нем содержится контента.

Эти теги нужно использовать в тех случаях, когда не нашелся иной, более подходящий по смыслу тег.


# 1_3_HTML_заголовки,_параграфы_и_списки_—_теги_h1_h6,_p,_ol,_ul_и






Для разметки заголовков существует шесть специальных тегов h1, h2 ... h6. Все они являются блочными, то есть занимает всю ширину экрана. Размер шрифта заголовков от h1 до h6 разный. Самый большой - h1, самый маленький - h6.

Есть несколько важных правил по использованию тегов заголовков. h1 - главный заголовок страницы и на каждой такой тег должен быть ровно один. Все заголовки на странице должны идти строго по порядку без внезапных пропусков уровней. Например, если у секции есть заголовок (обычно это тег h2), а внутри этой секции сразу размещены мини карточки товаров. Зачастую, у этих карточек тоже есть заголовок, тег у такого заголовка может быть только h3. Использовать уровень h4 будет ошибкой, так как в таком случае нарушится последовательность. Заголовки должны быть осмысленными. Если анализировать страницу в режиме просмотра только заголовков, то должно получиться осмысленное оглавление как у книги.

<b>Не очевидные выводы из правил</b>. Размер заголовка в макете не всегда соответствует его уровню. То есть размерами заголовка необходимо управлять через стили. Не все, что на макете выглядит как заголовок, будет являться им на уровне кода и чтобы соблюдать последовательность заголовков и их смысл, может потребоваться добавить визуально скрытые через CSS заголовки. 

Тег p - тег параграфа или абзаца. Как и теги заголовков, является блочным и занимает всю ширину и все, что находится внутри его. Новички часто допускают ошибку, когда оборачивают в тег параграфа абсолютно любой текст, даже состоящий из одного слова. В любой книге или статье каждый абзац состоит, как правило, из нескольких предложений. В разметке сайта применимы те же принципы. Оборачивайте в тег p как минимум одно полное предложение

О списках. Списки в html бывают двух видов - неупорядоченные маркированные и упорядоченные нумерованные. Тег неупорядоченного маркированного списка - ul, а тег упорядоченного нумерованного - ol

В обоих тегах дочерними элементами (их ближайшими внутренними тегами) являются теги li, определяющие элементы списка. Все вышеупомянутые теги списков являются блочными.

Важное правило! В тегах ul и ol в качестве прямых потомков могут быть только теги li, и никакие другие элементы, также нельзя просто так помещать текст внутри ul и ol без оборачивания его в тег li. Однако в свою очередь тег li может содержать внутри себя практически любые теги в любом количестве. Получается строгая последовательность. 

Дополнительно отмечу, что тег элемента списка не может использоваться сам по себе. Его прямым родительским элементом может быть либо тег ul, либо ol.

Списками в разметке стоит оборачивать не только списки дел или шаги рецепта, но и, в принципе, любую последовательность однотипных элементов. Например, список пунктов меню в шапке сайта, последовательность каких-либо кнопок, карточек и т.д


# 1_4_Форматирование_текста_в_HTML_—_теги_b_и_strong,_i_и_em,_s,_u



Для того чтобы видоизменять части текста, в разметке применяются так называемые теги форматирования, каждый из которых делает что-то одно: добавляет жирность, курсив, надстрочность и т.п.

Все теги форматирования текста являются строчными элементами и их можно использовать совместно друг с другом практически в любых комбинациях. То есть, можно сделать текст одновременно, например, жирным, курсивом и зачеркнутым. Для этого лишь нужно обернуть текст в определенный набор тегов

теги b и strong используются для того, чтобы сделать текст визуально более насыщенней. Разница между тегами заключается в том, что тег b просто выделяет текст, но не придает выделенному тексту никакой важности, а strong же, помимо визуального выделения, добавляет так называемую важность текста. Под важностью имеется в виду, что вспомогательные программы для работы с веб сайтами, такие как скрин ридеры, будут зачитывать текст с тегом strong более эмоционально, а тег b - по-обычному.  Тег strong можно использовать неоднократно, вкладывая их друг в друга для усиления степени важности. 

В большинстве ситуация, для выделения части текста жирным, применяйте тег b, а где наверняка требуется добавить еще и важное значение, используйте тег strong

Для выделения части текста курсивом, используются теги i и em. Курсивом в тексте могут обозначать смену тона голоса, другой язык или настроение части текста. Разница между этими двумя тегами аналогична с b и strong. i - простой курсив, em - курсив с особым смыслом. 

тег s используется для выделения текста, который уже потерял свою актуальность. Например, в случае с информацией о старой цене товара. Визуально это выглядит как перечеркнутый текст. 

тег u используется для выделения фрагмента текста, который стилистически отличается от остального текста. Например, слова с нарочитыми орфографическими ошибками в предложении

тег sub используется, чтобы сделать текст подстрочным. Например, его можно использовать, чтобы писать формулы химических соединений

H<sub>2</sub>0, H<sub>2</sub>SO<sub>4</sub>

тег sup используется, чтобы сделать текст надстрочным. Применяется, например, при написании степеней

тег small придает выделенному тексту мелкий размер шрифта. Обычно, используется для незначительных фраз, пояснений и т.д. Размер вводимого текста по умолчанию меньше на 20%, чем текст без данного тега.

тег mark выделяет важные фрагменты текста ярким фоном, по умолчанию желтым цветом. Можно использовать, например, в результатах поиска, чтобы выделить части запросов в найденном тексте

тег br указывает место разрыва строки, после которого текст нужно перенести на новую строку. Используется там, где важен принципиальный перенос текста. Например, в слоганах, в стихотворении или в адресе.

тег hr добавляет горизонтальную черту, которую обычно используют, чтобы разграничить контент на смысловые группы. При верстке каждый разработчик сталкивается с горизонтальными линиями, которые дизайнер нередко любит добавлять в свои макеты. Однако далеко не всегда стоит на уровне html реализовывать эти линии через hr. Иногда будет правильнее нарисовать линию через стили. Тег hr прежде всего важен для добавления логического разделения, без которого ухудшается понимание контента. Для сугубо декоративных деталей  тег hr использовать не стоит. 

тег code используется для вывода фрагментов кода. Тег делает обернутый в него текст моноширным. это когда каждый элемент в тексте имеет одинаковую ширину. 

По умолчанию браузер игнорирует множественные пробелы и перенос строк в html разметке, позволяя нам писать код так, как нам удобно. А что, если нам необходимо сохранить все пробелы и переносы строк? Например, нам нужно вынести рисунок из символов или многострочный код? Для таких случаев есть тег pre. Он предотвращает принудительное удаление пробелов и переносов строк при выводе разметки в браузере. 


# 1_5_HTML_ссылки_и_кнопки_—_теги_a,_button_Якорная_ссылка,_ссылка
Для навигации по страницам сайта и за его пределами в интернете используются ссылки. 

Тег а позволяет сделать текст, изображение или любой другой элемент ссылкой. Достаточно лишь обернуть нужное нам содержимое в тег a и указать корректный адрес в атрибуте href. Обернутый в тег a, выделенный контент станет ссылкой.

Ссылка может вести на любую страницу на текущем сайте или на любом другом в интернете. Может указывать на конкретный элемент текущей страницы, а также на файл, почту или телефон


```HTML
<!doctype html>
<html>
<body>
<a href="#contacts">Наши контакты</a>
<h1 id="contacts">Контакты...</h1>
<a href="./file.exe" download>Скачать файл</a>
<a href="mailto:fletwixgreyrat@gmail.com">
fletwixgreyrat@gmail.com
</a>
<a href="https://vk.com", target="_blank">
Наш ВК
</a>
<a href="tel:+79999999999">+7 (999) 999-99-99</a>
</body>
</html>
```


Иногда полезно сделать так, чтобы ссылка открывалась в новой вкладке. Для этого стоит указать атрибут target="_blank"

Теперь рассмотрим тег button. Данный тег имеет важный атрибут type, который принимает всего три значения: button, submit и reset. Первый тег прописывается всем кнопкам по умолчанию. Это визуально на уровне разметки дает нам понять, что перед нами не кнопка отправки формы и не кнопка сброса, также часто бывает такая ситуация, когда помимо кнопок с типом type и reset есть другие. Например, кнопка с иконкой глаза на поле ввода пароля. Если такой кнопке не прописать type="button", то при нажатии произойдет отправка формы. Это происходит из-за того, что html в формах неявно задает всем кнопкам без атрибута параметр submit.

Значение submit нужно использовать, если тег button лежит в формах, что подразумевает отправку каких-либо введенных пользователем данных на сервер. Например, кнопка "Войти" в форме авторизации. 

Значение reset тоже лежит в формах и выполняет ровно то, что мы от нее ожидаем - сбрасывает какие-либо введенные пользователем данные до данных по умолчанию.

Если при нажатии на элемент страницы подразумевается переход на другую страницу, то в коде элемент нужно сделать тегом a, а если при нажатии произойдет действие в рамках текущей страницы, то использовать button


# 1_6 HTML изображения — тег img. Относительные и абсолютные пути.

Для добавления изображения на страницу, есть несколько способов. Один из самых явных - использование html тега img. Тег img является одиночным и имеет один обязательный атрибут src. В значение атрибута указывается путь до файла изображения любого формата, который поддерживает браузер. Обычно это форматы jpeg, png, svg, gif, webp и т.д.

Помимо атрибута src хорошим тоном является добавлять еще атрибут alt. В значение атрибута прописывается альтернативное небольшое текстовое описание изображения. Этот текст в обычных ситуациях посетитель сайта не увидит и служит для других целей. Во-первых, если изображение по какой-либо причине не загрузится, то вместо изображения тег img отобразит текст из атрибута alt. 
```html
<!doctype html>
<html lang="ru">
<head>
	<title>Фоточки</title>
	<meta charset="UTF-8" />
	<meta name="description" content="Описание страницы" />
</head>
<body>
	<img src="images/photo.jpg"
	alt="Фотка"
	width="250" height="250">
</body>
</html>
```

Во-вторых, атрибут alt очень важен для пользователей с особенностями визуального восприятия, которые используют для чтения веб сайтов специальные программы, называемые скринридерами. Эти программы озвучивают контент на сайте, для того чтобы передать смысл тега изображения, зачитывают текст из атрибута alt тега img. Если атрибута alt не будет вовсе, то скринридеры будут зачитывать содержимое тега src, что, мягко говоря, будет неудобно в большинстве ситуаций.

Важный момент! Заполнять атрибут alt стоит только тем текстом, которые несут пользователям скринридеров нужную информацию. Если фото добавлено для декора, то атрибут нужно оставить пустым.

Также правильным считается заполнение тегов img атрибутами width и height. В разметке это считается важным, потому что программа сначала читает HTML, а уже после CSS, а так как медиаконтент в некоторых случаях запускается не мгновенно, и на месте размер изображения будет 0 пикселей, а после прогрузки CSS фото займет условные 250 пикселей, что изменит интерфейс сайта (а такое может быть и не раз, если изображений на странице много).

В разметке браузер в первую очередь читает все теги img и загружает их, но зачем нам тормозить загрузку сайта, если фотография еще какое-то время не будет видеться пользователем? На этот случай в html есть lazy loading (ленивая загрузка), указывается значение в атрибуте loading
- `lazy`: указывает на материалы, которые являются хорошими кандидатами на ленивую загрузку.
- `eager`: материалы в элементах с таким значением атрибута нужно загрузить без промедления.
- `auto`: браузер самостоятельно примет решение о том, применять ли к материалам с этим значением атрибута ленивую загрузку.
