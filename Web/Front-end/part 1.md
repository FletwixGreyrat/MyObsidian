# 2 Гайд по CSS-селекторам, расчёт специфичности в CSS. Приоритет и вес стилей


Селектор по тегу - самый простой селектор, выбирает все теги на странице по его названию.

Селектор по классу - самый частый в использовании. Работает прописыванию атрибута class элементу. Значение class - селектор .{значение класса}. Классов для элементов можно прописать сколько угодно через пробел

Селектор по id. Работает так же, как и селектор по классу, только прописывается #{значение атрибута id}. Отличаются они в уникальности. Значение атрибута id может встречаться лишь раз, а еще нельзя прописать айди через пробел

Селектор по атрибуту. Записывается в файле стилей как  [{имя}="{значение}"] или [{имя}]

[{имя}*={значение}] - аналог оператора in

[{имя}^={значение}] - аналог функции startswith

[{имя}$={значение}] - аналог функции endswith

[{имя}~={значение}] - аналог оператора in, но умнее, смотрит на пробелы

[{имя}|={значение}] - проверка на равенство, или на startswith={значение}-

[{имя}{что-нибудь необязательно}={значение} i] - i игнорирует регистр, также допустимо I. Важно: с кириллицей работать не будет 

\* - универсальный селектор, позволяет выбрать все элементы на странице

{селектор 1},
{селектор 2},
{селектор 3} {

} -  множественный стиль


.{селектор 1}.{селектор 2} - применения стиля к элементу, со всеми указанными значениями атрибута class

{элемент 1} > {элемент 2} - прямой дочерний элемент

{элемент 1} + {элемент 2} - следующий в разметке с таким же уровнем вложенности

{элемент 1} ~ {элемент 2} - все следующие в разметке с таким же уровнем вложенности

# 3 Блочная модель в CSS — свойства display, width, height, padding, margin, border и box-sizing


Блочная модель в CSS - это алгоритм расчета размеров каждого отдельно взятого элемента страницы. Схему блочной модели можно посмотреть у любого элемента через инструмент браузерного разработчика.

Блочная модель - это совокупность CSS свойств, влияющих на размер элемента. С этим свойствам относятся:
- width - ширина
- height - высота
- padding - внутренние отступы от содержимого (от контента до краев элемента)
- margin - внешние отступы вокруг элемента
- border - рамка, идущая по краю элемента

Свойства ширины и высоты (width и height) задают размеры контентной области элемента. Контентная область - внутреннее пространство, отведенное под то, что мы поместили внутрь элемента.

У каждого элемента есть параметр типа отображения, это свойство display. У тега div в значении display по умолчанию это блок (display block), мы можем явно указать это в display правиле, но в данном случае это необязательно. Тип отображения "block" говорит о том, что элемент блочный и если мы не задали конкретное значение ширины в свойстве width, то элемент будет занимать всю доступную ему ширину, а вот высота элемента по умолчанию всегда будет подстраиваться под содержимое, под внутренний контент

Если же мы зададим блоку конкретные размеры, свойства width и height, то мы можем увидеть, как изменятся границы элемента. Важное отступление: задавать элементам фиксированное значение высоты и ширины - это плохая практика, если у элемента заданы конкретные размеры, то мы берем на себя ответственность за то, что контент внутри блока никогда не поменяется, а гарантировать это мы не можем, да и не должны

Дефолтное значение height - auto 

Помимо блочного типа отображения есть еще и строчный. Рассмотрим тег span, по умолчанию он строчный,  то есть у него значение свойства display по умолчанию это inline. Указывать это правило явно в CSS необязательно, тип отображения inline говорит о том, что элемент строчный и его ширина будет равна ширине его внутреннего содержимого, а высота как и у блочного равна высоте внутреннего контента, получается, что блочный и строчный элемент имеет размеры как у его внутреннего содержимого.

Строчным инлайн элементам нельзя задавать ширину и высоту, это просто напросто не сработает, а


Еще одно свойство display - это inline-flex. Такое значение делает элемент блочно-строчным. Отличия: ему можно прописать width и height

У свойства display есть еще одно очень интересное значение - none, оно полностью скрывает элемент со страницы, несмотря на то, что в разметке данный элемент будет присутствовать. Подобный элемент сокрытия элемента применяется очень часто. Информация на будущее: свойство display не анимируется, то есть плавное появление элемента через display none не получится, для этого есть другие механики. 

Свойство padding - задает внутренние отступы. По умолчанию в контексте разговора о блочной модели внутренние отступы от padding прибавляются к высоте и ширине элемента 

Свойство border - добавляет элементу рамку. Синтаксис свойства следующий: ширина рамки, тип линии и ее цвет. Параметры разделяются пробелом и их можно писать в любом порядке. Рамка, как и внутренние отступы, по умолчанию влияют на размеры элемента. Теперь итоговая фактическая ширина элемента.

Свойство margin - задает внешние отступы, они не прибавляются к фактическим размерам элемента, но являются частью блочной модели и влияют на то, сколько места на странице займет элемент, чтобы было проще понять это свойство, margin толкает все вокруг этого элемента на указанное значение.

Свойство box-sizing - меняет формулу расчета фактической ширины и высоты элемента, делает так, что элемент будет иметь размеры ровно такие же, какие и заданы в его значениях width и height и ни padding, ни border не будут увеличивать размеры элементов, так как они будут включены в формулу расчета фактических размеров. Значений у свойства два - content-box (по умолчанию), border-box


# 4. CSS внутренние и внешние отступы — свойства padding и margin. Схлопывание отступов



Свойство padding - задает величину внутреннего отступа от края элемента до его внутрненнего содержимого. По умолчанию у большинства HTML тегов значение внутренних отступов padding равно нулю, лишь у тегов ol и ul есть небольшой внутренний отступ слева. В браузере Chrome это значение 40 пикселей. Значение по умолчанию обычно сбрасывают

Для задания элементу внутренних отступов padding есть несколько способов и форматов значений

Если в padding указать одно значение, то внутренние отступы добавятся со всех сторон.

Если указать два значения через пробел, то первое число будет задавать отступы по вертикали, а второе - по горизонтали

Если указать три значения через пробел, то первое число будет задавать отступ сверху, второе будет по горизонтали и третье снизу

Если указать четыре значения, то отступы будут заданы по часовой стрелке

Отдельно отступы указываются через подсвойства:
 - padding-top - сверху
 - padding-right - справа
 - padding-bottom - снизу
 - padding-left - слева
 - padding-block - по вертикали
 - padding-inline - по горизонтали

Свойство margin - задает величину внешнего отступа вокруг элемента. Браузеры некоторым html тегам задают по умолчанию определенное значение отступов margin, для тегов заголовков, списков, параграфа и некоторых других

Перейдем к форматам значений. Синтаксис внешних отступов аналогичен синтаксису внутренних отступов. Внешние отступы, в отличие от внутренних, не являются непосредственной частью элемента, на то они и внешние отступы. Каждые из блоков этой страницы стоит рассматривать в совокупности, нам важно понять, как внешние отступы ведут себя по отношению к соседним элементам

Помимо аналогичных padding свойств, у padding есть значение auto, это значение говорит, чтобы браузер сам выбрал подходящий размер внешнего отступа

В margin есть отрицательные значения, так элемент заедет на другие элементы

Схлопывание отступов - поведение пересекающихся внешних отступов

# 8. CSS фоновый цвет, изображение, градиент — свойство background, функция linear-gradient


свойство background - это обобщенное свойство, которое позволяет задать одной строкой множество параметров фона: фоновый цвет, изображение, режим повторений изображения, позиций изображения, размер изображения, режим фона при прокрутке и область применения (последние два параметра применяются чрезвычайно редко). Параметры можно прописывать практически в любом порядке. Единственное правило - параметры позиций изображения и размеры идут строго друг за другом и разделяются с помощью слэша, а теперь рассмотрим все подсвойства в подробностях


background-color - задает элементу фоновый цвет, в качестве значения можно указать все те форматы, что и в прошлом конспекте

background-image - задает элементу фоновое изображение или градиент. 
```css
background-image: url("./cat.jpg")
```

background-repeat - задает режим повторения изображения. Можно указать два значения : одно отвечает за ось x, другое за ось y, если один элемент, то за обе оси.  

background-position - управляет позиционированием изображения. Значение по умолчанию - 0, 0 (горизонталь и вертикаль, одно число - онли горизонталь), обычно значения указывают в пикселях или процентах

background-size - отвечает за размеры элемента, значение по умолчанию - auto, при этом размеры будут как у оригинального файла изображения

background-attachment - задает правила фона при скролле, значение по умолчанию - scroll. Фон жестко привязан к элементу и при скролле странице ничего особенного с фоном страницы не происходит. Значение fixed будет зафиксировано относительно родительского прокручиваемого элемента. При значении local фон будет прокручиваться в зависимости от поведения элемента. 

background-clip - определяет в какой области блочной модели элемента будет находиться фон, изображение и цвет, значений у этого свойства несколько. border-box - значение по умолчанию, фон займет всю область элемента, в том числе залезет под рамку элемента. padding-box - фон займет всю область, но не будет залезать под рамку. Значение content-box - фон займет только контентную область, то есть не будет залезать на рамку и на область от внутреннего отступа padding. значение text - фон будет применен к текстовому содержимому элемента. Это значение заработает, только если у свойства цвета текста color задано значение transparent (прозрачность), но в хроме не работает, нужно продублировать background-clip c указанием в начале имени вендорного префикса -webkit- (об этом позже). 

Градиенты
Градиенты задаются фоном к элементу через свойство background-image. в CSS существует три вида градиентов - линейный, радиальный и конический. Каждому виду градиента соответствует функция: linear-gradient, radial-gradient, conic-gradient. у каждой из функций есть дополнительная с префиксом repeating-, для которой для каждого цвета нужно задавать размеры, и таким образом для градиента будет задан повторяющийся паттерн.

Градиенты - не самая простая тема, да и глубокое их познание может не пригодиться вовсе, поэтому подробно рассмотрим лишь самые популярный вид градиента - линейный. Стандартный синтаксис функции linear-gradient простой, мы просто перечисляем в скобках цвета, минимум два, пропорции занимаемых цветов будут равны

направление градиента можно менять, для этого в самом начале функции указать угол в градусах (от 0 до 360, единица измерения deg), по умолчанию 180 градусов (сверху вниз). Запись можно вести и в turn'ах (1 turn - 360 градусов).

направление градиента можно также задавать через ключевые слова, их всего 8:
- to top
- to top right
- to right
- to bottom
- to bottom left
- to left
- to left top

В градиенте можно управлять точками перехода цвета, а именно задать в любой единице измерения граничные значения цвету сразу после него, через пробел. Первое - при котором плавно закончится переход из предыдущего цвета, а второе - с которого плавно начется переход в следующий цвет. Если конченая точка предыдущего цвета и начальная точка следующего цвета совпадает, то переход между цветами будет мгновенный, без плавности. 

Обычно градиенты не пишутся вручную, а берутся из, например, cssgradient.io


Новички и не только часто задают цвет через обобщенное свойство color, например, background: red. Смысла в такой записи мало. Если для указания одного лишь цвета мы используем общее свойство background, то браузер переопределит все подсвойства, которые могли быть заданы ранее. Чтобы избежать лишних переопределений, для задания лишь одного подсвойства лучше изменять его точечно. Совет относится и к другим свойствам (font, margin, padding и подобным)


# 9. CSS рамка border, обводка outline, тени box-shadow, фильтры filter


border - задает элементу рамку, это свойство-шорткат (border-width, border-style, border-color)

свойство border задает рамку по всем границам элемента, но если нужна с конкретной стороны, то на этот случай есть -left, -right, -top, -bottom, -block (сверху и снизу), -inline (слева и справа)

для задания ширины рамки используется свойство border-width, значение можно указать в пикселях, емах, рэмах и вьюпорт единицах, но не в процентах. Для этого свойства существуют ключевые слова thin и thick (не популярно). Можно указать от одного до четырех значений ширины, распределяться все будет так же, как в margin и padding.

border-style - задает стиль рамки.  У этого свойства существует около десятка ключевых слов:
- none
- solid - сплошная линия
- dashed - короткие черточки
- dotted - точки
- double - двойная рамка с небольшим отступом между линиями
- groove
- ridge
- inset
- outset
Рассказывать о разнице между последними четырьмя сложно, все они - рамки с тенями, отличается лишь угол, на который падает тень.

border-style тоже можно прописать для отдельной стороны через -right- -left- и прочее

border-color - цвет рамки, можно указать от одного до четырех значений. Можно прописать для отдельной стороны через -right- -left- и прочее

Рамка border по умолчанию не включена в размеры элемента, заданные через width и height. Если указать box-sizing: border-box, то размеры будут включены в указанную ширину и высоту

outline - задает обводку элемента, но не влияет на его фактические размеры. Это свойство шорткат (outline-width, outline-style, outline-color). Обводку нельзя задать для одной или нескольких сторон, она применяется со всех сторон. Но есть у него свойство, которого нет у border - outline-offset. Оно задает смещение обводки относительно краев элемента, можно указывать положительные и отрицательные значения. 

border-radius - закругление элемента. Не имеет ничего общего с border, кроме названия, значение можно указать в любых единицах измерения, но обычно в пикселях и процентах. Можно перечислить до четырех элементов. Конфигурировать красивые фигуры можно на сайте 9elements.github.io/fancy-border-radius.

Поговорим о связи border-radius и outline, года 4 назад закругления не действовали на обводку, поэтому в старых курсах, учебниках и гайдах советуют не использовать их вместе, теперь же нет смысла опасаться связи outline и border-radius

для задания тени существует свойство box-shadow. Вариаций использования несколько:
- Если задать два значения (можно задавать как положительные, так и отрицательные), то под элементом появится черная тень, смещенная на x значений вправо и на y значений вниз

Смещение по осям можно указывать в любых единицах измерения, кроме процентов, однако чаще всего используют пиксели

 - Если добавить третье значение, то оно будет отвечать за радиус размытия (только положительное значение, можно использовать любые единицы измерения, кроме процентов)
- Если добавить четвертое значение, то оно будет отвечать за радиус распространения (грубо говоря, за размеры этой тени). Это значение может быть отрицательным, тогда тень за элементом будет меньше чем фактические размеры элемента
- Пятым элементом можно указать цвет тени

Для box-shadow есть также специальное свойство inset, которое при добавлении к свойству меняет положение тени с внешней на внутреннюю. Через запятую в свойстве можно указывать несколько теней 

filter - с помощью него можно наложить на элемент множество фильтров, как в популярных фоторедакторах.
