### **Домашнее задание по HTML**

#### **1. Основы HTML**
1. Объясни своими словами, что такое HTML и для чего он нужен в создании веб-страниц.
2. Приведи 3 примера парных тегов и 2 примера одиночных тегов. Почему для одиночных тегов рекомендуется использовать синтаксис с "/" в конце?
3. Что такое потоки в HTML? Как браузер обрабатывает HTML-документ?
4. Создай базовую структуру HTML-документа с обязательными тегами: doctype, html, head, body. Добавь метатеги для кодировки UTF-8 и адаптивности.
5. Для чего нужен атрибут lang в теге html? Что произойдет, если указать неправильное значение этого атрибута?
6. Почему тег title важен для веб-страницы? Где именно он отображается?
7. Можно ли в документе иметь несколько тегов body? Почему?

#### **2. Блочные и строчные элементы**
1. В чем принципиальная разница между блочными и строчными элементами? Приведи по 3 примера каждого типа.
2. Почему нельзя вкладывать блочный элемент внутрь строчного? Приведи пример неправильной и правильной вложенности.
3. Что такое семантическая верстка? Почему важно использовать теги по их назначению?
4. В каких случаях следует использовать div, а в каких span? Приведи конкретные примеры.
5. Создай структуру: блок header с заголовком h1 и ссылкой, блок content с абзацем текста, где часть текста выделена жирным.
6. Какие проблемы могут возникнуть, если использовать div для всех элементов страницы без учета семантики?
7. Можно ли поместить тег p внутрь тега span? Почему? Как правильно сделать в таком случае?

#### **3. Заголовки, параграфы и списки**
1. Сколько уровней заголовков существует в HTML? Почему нельзя пропускать уровни (например, использовать h1, а затем сразу h3)?
2. Почему на странице должен быть только один h1? Какие последствия могут быть при использовании нескольких h1?
3. В каких случаях следует использовать тег p? Можно ли использовать p для одного слова? Почему?
4. Какие существуют типы списков в HTML? Чем они отличаются?
5. Создай нумерованный список из 5 шагов приготовления кофе. В третьем шаге добавь вложенный маркированный список необходимых ингредиентов.
6. Почему внутри ul или ol могут быть только li? Что произойдет, если поместить туда другой тег?
7. В каких случаях следует использовать списки для разметки, даже если это не выглядит как традиционный список?
