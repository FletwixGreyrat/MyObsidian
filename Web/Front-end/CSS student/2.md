
# 🧠 Полный гайд по CSS-селекторам и специфичности

CSS-селекторы позволяют выбрать HTML-элементы и применить к ним стили. Давайте рассмотрим каждый тип селектора с примерами и объяснениями.

---

## 📌 Селектор по тегу

Выбирает все элементы определённого типа на странице.

**CSS:**
```css
p {
  color: blue;
}
```

**HTML:**
```html
<p>Это абзац</p>
<p>И это тоже абзац</p>
```

Все теги `<p>` станут синими.

---

## 📌 Селектор по классу

Выбирает элементы с определённым значением атрибута `class`.

**CSS:**
```css
.box {
  border: 1px solid black;
}
```

**HTML:**
```html
<div class="box">Контейнер</div>
<div class="box">Ещё один контейнер</div>
```

Можно применять несколько классов к одному элементу:

```html
<div class="box large">Большой контейнер</div>
```

---

## 📌 Селектор по ID

Выбирает элемент по уникальному идентификатору. На странице не должно быть двух элементов с одним и тем же ID.

**CSS:**
```css
#main {
  background-color: lightgray;
}
```

**HTML:**
```html
<div id="main">Главный блок</div>
```

❗ В отличие от классов, ID не может содержать пробелы и должен быть уникальным.

---

## 📌 Селектор по атрибуту

Позволяет выбрать элементы по наличию или значению атрибута.

### Примеры:

```css
input[type="text"] {
  border: 1px solid blue;
}

a[href^="https"] {
  color: green;
}

img[alt$=".jpg"] {
  border: 2px solid red;
}
```

**HTML:**
```html
<input type="text" placeholder="Введите текст">
<a href="https://example.com">Ссылка</a>
<img src="image.jpg" alt="example.jpg">
```

### Специальные формы:

- `[attr*="value"]` — содержит подстроку
- `[attr^="value"]` — начинается с
- `[attr$="value"]` — заканчивается на
- `[attr~="value"]` — содержит слово (разделённое пробелами)
- `[attr|="value"]` — точно равно или начинается с `value-`
- `[attr="value" i]` — сравнение без учёта регистра

---

## 📌 Универсальный селектор `*`

Выбирает **все** элементы на странице.

**CSS:**
```css
* {
  margin: 0;
  padding: 0;
}
```

---

## 📌 Группировка селекторов

Позволяет применить один стиль к нескольким селекторам.

**CSS:**
```css
h1, h2, h3 {
  font-family: sans-serif;
}
```

---

## 📌 Селектор с несколькими классами

Выбирает элемент, у которого **все** указанные классы присутствуют.

**CSS:**
```css
.card.featured {
  border: 2px solid gold;
}
```

**HTML:**
```html
<div class="card featured">Карточка</div>
```

---

## 📌 Дочерние селекторы

### Прямой потомок (`>`)

**CSS:**
```css
ul > li {
  color: red;
}
```

**HTML:**
```html
<ul>
  <li>Элемент</li>
  <ul><li>Вложенный</li></ul>
</ul>
```

Только первый уровень `<li>` будет красным.

---

### Следующий сосед (`+`)

**CSS:**
```css
h1 + p {
  color: gray;
}
```

**HTML:**
```html
<h1>Заголовок</h1>
<p>Первый параграф после заголовка</p>
<p>Второй параграф</p>
```

Только первый `<p>` после `<h1>` станет серым.

---

### Все следующие соседи (`~`)

**CSS:**
```css
h1 ~ p {
  font-style: italic;
}
```

**HTML:**
```html
<h1>Заголовок</h1>
<p>Параграф 1</p>
<p>Параграф 2</p>
```

Все `<p>`, следующие за `<h1>`, станут курсивными.

---

## 🧮 Специфичность и приоритет

CSS определяет, какой стиль применить, если несколько правил подходят к одному элементу. Это зависит от специфичности селектора.

**Общие принципы:**
- Чем **точнее** селектор, тем он важнее:
  - `#id` — самый специфичный
  - `.class`, `[attr]` — средняя специфичность
  - `tag` — низкая специфичность
- Если специфичность одинаковая, срабатывает **последнее по порядку** правило.

**Пример:**
```css
p {
  color: black;
}
.text {
  color: red;
}
#special {
  color: blue;
}
```

**HTML:**
```html
<p id="special" class="text">Текст</p>
```

Этот `<p>` будет синим, потому что `#special` имеет наибольшую специфичность.
