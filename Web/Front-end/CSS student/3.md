
# 📦 Гайд по блочной модели в CSS

Блочная модель описывает, как рассчитываются размеры HTML-элементов на веб-странице. Она включает в себя свойства: `width`, `height`, `padding`, `margin`, `border` и `box-sizing`.

---

## 🧱 Основы блочной модели

Каждый элемент состоит из следующих слоев:

- **Content** (содержимое)
- **Padding** (внутренние отступы)
- **Border** (рамка)
- **Margin** (внешние отступы)

---

## 📐 Свойства `width` и `height`

Эти свойства определяют ширину и высоту **контентной области**.

**CSS:**
```css
.box {
  width: 200px;
  height: 100px;
}
```

**HTML:**
```html
<div class="box">Контент</div>
```

📌 По умолчанию `height: auto` — элемент подстраивается под содержимое.

---

## 🧾 Свойство `display`

Определяет тип отображения элемента.

### `block`

Блочный элемент занимает всю доступную ширину.

```css
div {
  display: block;
}
```

```html
<div>Блок</div>
```

### `inline`

Строчный элемент занимает ширину по содержимому.

```html
<span>Текст</span>
```

📌 Нельзя задать `width` и `height`.

### `inline-flex`

Комбинация inline и flex. Можно задавать размеры.

```css
.inline-flex-box {
  display: inline-flex;
  width: 150px;
  height: 50px;
}
```

### `none`

Полностью скрывает элемент.

```css
.hidden {
  display: none;
}
```

```html
<div class="hidden">Этого не видно</div>
```

📝 `display: none` не анимируется.

---

## 📏 Свойство `padding`

Внутренние отступы от содержимого до границы элемента.

```css
.box {
  padding: 20px;
}
```

```html
<div class="box">С отступами</div>
```

📌 Увеличивает размеры элемента по умолчанию.

---

## 🔲 Свойство `border`

Рамка вокруг элемента. Формат: `толщина тип цвет`.

```css
.box {
  border: 2px solid red;
}
```

```html
<div class="box">С рамкой</div>
```

📌 Также влияет на размеры по умолчанию.

---

## 🌌 Свойство `margin`

Внешние отступы вокруг элемента.

```css
.box {
  margin: 30px;
}
```

```html
<div class="box">Снаружи отступ</div>
```

📌 Не влияет на фактические размеры элемента, но влияет на размещение.

---

## 🔧 Свойство `box-sizing`

Определяет, как рассчитывается итоговый размер элемента.

### `content-box` (по умолчанию)

Размеры считаются **без учёта** `padding` и `border`.

### `border-box`

Размеры считаются **вместе с** `padding` и `border`.

```css
.box {
  width: 200px;
  padding: 20px;
  border: 5px solid black;
  box-sizing: border-box;
}
```

```html
<div class="box">Точный размер</div>
```

📌 Это удобно: элемент будет **ровно** 200px в ширину, включая отступы и границы.
