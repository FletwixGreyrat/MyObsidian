
# 🧲 Гайд по внутренним и внешним отступам в CSS (padding и margin)

Отступы — важная часть вёрстки: они создают пространство вокруг и внутри элементов. Разберёмся, как работают `padding`, `margin` и что такое схлопывание отступов.

---

## 📥 Свойство `padding` — внутренние отступы

`padding` задаёт расстояние **от края элемента до его содержимого**.

### Значения по умолчанию

У большинства тегов `padding: 0`, кроме некоторых, например:

```html
<ul>
  <li>Элемент списка</li>
</ul>
```

В браузере Chrome у `<ul>` слева будет `padding-left: 40px`.

### Форматы записи

```css
padding: 20px;          /* со всех сторон */
padding: 10px 20px;     /* вертикаль | горизонталь */
padding: 10px 15px 5px; /* сверху | по бокам | снизу */
padding: 5px 10px 15px 20px; /* по часовой стрелке: сверху, справа, снизу, слева */
```

### Подсвойства

```css
padding-top: 10px;
padding-right: 20px;
padding-bottom: 30px;
padding-left: 40px;
```

Также можно использовать логические свойства:

```css
padding-block: 10px;   /* сверху и снизу */
padding-inline: 15px;  /* слева и справа */
```

---

## 📤 Свойство `margin` — внешние отступы

`margin` — это пространство **вокруг** элемента.

### Значения по умолчанию

Многие теги получают `margin` по умолчанию:

```html
<h1>Заголовок</h1>
<p>Параграф</p>
```

У них браузер задаёт внешние отступы, например, `margin-top` и `margin-bottom`.

### Форматы записи аналогичны `padding`:

```css
margin: 10px;              /* со всех сторон */
margin: 10px 20px;         /* вертикаль | горизонталь */
margin: 10px 15px 5px;     /* сверху | по бокам | снизу */
margin: 5px 10px 15px 20px;/* по часовой стрелке */
```

### Подсвойства

```css
margin-top: 10px;
margin-right: 20px;
margin-bottom: 30px;
margin-left: 40px;
```

### Специальные значения

- `auto` — браузер сам рассчитывает значение (часто используется для центрирования блоков).
- отрицательные значения `margin` позволяют "наехать" на соседние элементы.

```css
.centered-box {
  margin: 0 auto;
  width: 200px;
}
```

---

## ⚠️ Схлопывание отступов (margin collapsing)

Схлопывание происходит, когда внешние отступы двух вертикально расположенных блоков соприкасаются.

### Пример

```html
<div class="block1">Первый блок</div>
<div class="block2">Второй блок</div>
```

```css
.block1, .block2 {
  margin-top: 20px;
  margin-bottom: 30px;
}
```

📌 Вместо 20 + 30 = 50px между блоками получится **30px**, так как вертикальные margin схлопываются — применяется **наибольшее** значение.
