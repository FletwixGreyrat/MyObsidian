

## История компьютеров

Первые вычислительные устройства появились задолго до современных компьютеров. Примером механических вычислителей служит абак, использовавшийся в древних цивилизациях. В XVII веке появились механические калькуляторы, такие как машина Блеза Паскаля и шаговый калькулятор Готфрида Лейбница.

В XIX веке Чарльз Бэббидж разработал концепцию аналитической машины — прототипа программируемого компьютера. Однако, только в середине XX века появились электронные компьютеры. Одним из первых был ENIAC (1946 г.), занимавший огромную площадь и обладавший минимальными по сравнению с современными машинами возможностями. Позднее были разработаны транзисторы, что позволило создать более компактные и производительные ЭВМ. С развитием интегральных схем появились персональные компьютеры (ПК), а далее — ноутбуки, смартфоны и планшеты.

## Этапы развития:

- Механические компьютеры (абак, механические калькуляторы)
    
- Электромеханические (реле, переключатели)
    
- Электронные на лампах (ENIAC, UNIVAC)
    
- На транзисторах и интегральных схемах (IBM PC, Apple II)
    
- Современные микрокомпьютеры и мобильные устройства
    

## Основные компоненты компьютера

Компьютер — это совокупность аппаратных и программных средств, способных обрабатывать информацию.

## Главные аппаратные компоненты:

- **Процессор (CPU)** — выполняет вычисления, интерпретирует инструкции программ.
    
- **Оперативная память (RAM)** — хранит данные и программы для быстрого доступа во время работы.
    
- **Жёсткий диск (HDD) / Твердотельный накопитель (SSD)** — долговременное хранение данных.
    
- **Материнская плата** — объединяет все компоненты в единую систему.
    
- **Видеокарта (GPU)** — отвечает за обработку графики.
    
- **Блок питания** — снабжает компоненты электроэнергией.
    
- **Периферийные устройства**: монитор, клавиатура, мышь, принтер, сканер и др.
    

## Различия между настольными и портативными компьютерами

| Параметр               | Настольный компьютер            | Портативный компьютер (ноутбук, нетбук) |
| ---------------------- | ------------------------------- | --------------------------------------- |
| Размер                 | Крупнее, стационарен            | Компактен, мобильный                    |
| Апгрейд (модернизация) | Легко заменяемые детали         | Ограниченная возможность обновления     |
| Производительность     | Обычно выше                     | Могут уступать по мощности              |
| Энергопитание          | Работает от сети                | Встроенный аккумулятор                  |
| Портативность          | Нет                             | Легко переносим                         |
| Стоимость              | Соотношение цена/мощность лучше | Может быть выше за мобильность          |

Применение зависит от потребностей: для работы дома с требовательными программами часто используют настольные ПК, а для учебы и путешествий — ноутбуки и планшеты.


## Обзор популярных операционных систем

Операционная система (ОС) — основное программное обеспечение, управляющее оборудованием, обеспечивает взаимодействие между пользователем и компьютером.

## Основные ОС:

- **Windows** — самая распространённая для настольных ПК и ноутбуков. Известна своими пользовательскими удобствами, поддержкой огромного количества программ и оборудования.
    
- **macOS** — применяется на компьютерах Apple. Славится надёжностью, стабильностью и уникальным дизайном интерфейса.
    
- **Linux** — свободная ОС с открытым исходным кодом. Имеет многочисленные дистрибутивы (Ubuntu, Fedora, Mint), часто применяется для серверов, научных задач, а также на пользовательских ПК.
    

## Основы работы с интерфейсом

Интерфейс ОС — это набор средств взаимодействия пользователя с системой.

- **Графический интерфейс (GUI):**
    
    - Рабочий стол
        
    - Окна программ
        
    - Значки и ярлыки
        
    - Панели задач и меню
        
- **Командная строка (CLI):**
    
    - Символ приглашения (cmd в Windows, Terminal в macOS и Linux)
        
    - Работа с командами для продвинутых пользователей
        

Пользователь может запускать и закрывать приложения, переключаться между задачами, настраивать внешний вид рабочего стола, управлять звуком и питанием.

## Управление файлами и папками

Работа с файлами — основа взаимодействия с компьютером. ОС предоставляет файловую систему для хранения и структурирования файлов.

- **Создание, переименование и удаление файлов и папок**
    
- **Копирование и перемещение данных** между папками и устройствами
    
- **Использование корзины** (или «мусора»), для временного хранения удалённых файлов
    
- **Поиск файлов** с помощью встроённых инструментов
    
- **Различие типов файлов:** текстовые, мультимедийные, программные, архивы и пр.
    

В ОС существуют стандартные папки: "Документы", "Изображения", "Загрузки", "Музыка" и т.д., что облегчает организацию данных.

# Занятие 3: Основы интернета

## Понимание интернета и веб-браузеров

**Интернет** — глобальная система объединённых между собой компьютерных сетей. Она позволяет обмениваться информацией, файлами, общаться, использовать облачные сервисы.

**Веб-браузер** — программа для просмотра веб-страниц (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari и др.). С помощью браузера можно:

- Вводить адрес сайта (URL) в адресную строку
    
- Переходить по гиперссылкам
    
- Сохранять закладки интересных сайтов
    
- Использовать расширения и плагины для расширения возможностей
    

## Поиск информации в интернете

Для поиска информации обычно используют поисковые системы (Google, Яндекс, Bing). Типичный процесс поиска:

- Ввод ключевых слов в строку поиска
    
- Анализ результатов на первой странице (заголовки, краткие описания)
    
- Оценка достоверности источников (официальные сайты, проверенные публикации)
    

Советы по эффективному поиску:

- Использование кавычек для поиска точной фразы
    
- Добавление уточняющих слов (например, город, год)
    
- Использование фильтров поиска (по времени, типу контента)
    

## Основы электронной почты

Электронная почта (e-mail) — способ обмена сообщениями через интернет.

## Основные элементы:

- **Электронный ящик** — адрес вида [user@example.com](mailto:user@example.com)
    
- **Приложения для почты:** Microsoft Outlook, Gmail, Яндекс.Почта, мобильные почтовые клиенты
    
- **Входящие, отправленные, спам, корзина** — стандартные папки
    
- **Вложения:** отправка файлов вместе с письмом
    

## Процесс отправки письма:

1. Открыть почтовый клиент или веб-интерфейс
    
2. Нажать кнопку «Создать письмо»
    
3. Ввести адрес получателя, тему сообщения, текст письма
    
4. При необходимости прикрепить файл
    
5. Отправить письмо
    

Также важно соблюдать цифровую гигиену: не открывать подозрительные письма, использовать сложные пароли, чтобы защитить свой аккаунт.
