
Для выполнения задач на этапе постэксплуатации используются различные инструменты:

- **Metasploit** — предоставляет множество модулей для закрепления доступа, скрытия следов, эксфильтрации данных и горизонтального перемещения.
- **Empire** — мощный фреймворк для работы с Windows и Linux, включает модули для закрепления доступа, эксфильтрации данных и скрытности.
- **BloodHound** — для анализа доверенных связей в сетях на базе Active Directory и поиска путей для расширения доступа.
- **LaZagne** — утилита для кражи учетных данных из различных приложений.
- **PsExec и CrackMapExec** — инструменты для горизонтального перемещения в средах Windows.
