
##### **1. Закрепление доступа (Persistence)**

Одной из первых задач после успешного взлома является **закрепление доступа**, чтобы атакующий мог вернуться в систему позже, даже если администраторы обнаружат первоначальную уязвимость и устранят её. Закрепление может быть выполнено различными способами:

- **Установка бекдора** — злоумышленник может установить скрытую программу или изменить системные файлы для создания "задней двери", через которую можно будет войти в систему в будущем.
    
- **Создание новой учетной записи** — создание учетной записи с повышенными правами доступа (например, администратора), которая может не привлекать внимания.
    
- **Использование cron job или планировщика заданий (Windows Task Scheduler)** — программирование автоматического запуска вредоносного кода при перезагрузке или по расписанию.
    
    **Инструменты**:
    
    - **Metasploit** — модуль `persistence`, который автоматически создает бекдор для сохранения доступа.
    - **Empire** — фреймворк для закрепления доступа через различные методы в Windows и Linux.

##### **2. Сбор данных (Data Gathering)**

На этапе постэксплуатации атакующий собирает как можно больше полезной информации. Это могут быть:

- **Учетные данные (Credentials)** — пароли, ключи SSH, токены аутентификации.
    
- **Финансовая информация** — данные о банковских транзакциях, номерах кредитных карт.
    
- **Личные данные** — файлы с конфиденциальной информацией (например, персональные данные сотрудников или клиентов).
    
- **Конфигурационные файлы** — файлы конфигурации систем и приложений могут содержать критические данные, такие как пароли, ключи API, или указания на другие уязвимости.
    
    **Инструменты**:
    
    - **Mimikatz** — инструмент для извлечения паролей из памяти в системах Windows.
    - **LaZagne** — утилита для сбора учетных данных из различных приложений на локальной машине.
    - **Windows Credential Editor (WCE)** — утилита для кражи учетных данных из памяти Windows.

##### **3. Эксфильтрация данных (Data Exfiltration)**

После сбора ценной информации злоумышленник должен безопасно передать её на свою сторону. Это процесс **эксфильтрации данных**, который может быть выполнен через разные методы:

- **FTP/SFTP** — злоумышленник может настроить передачу данных через FTP/SFTP-сервер.
    
- **HTTP/HTTPS** — данные можно передать через веб-запросы, чтобы скрыть трафик в легитимных HTTP-пакетах.
    
- **DNS-туннелирование** — передача данных через DNS-запросы для обхода сетевых фильтров и обнаружения.
    
    **Инструменты**:
    
    - **Netcat** — утилита для передачи файлов и данных через сетевые соединения.
    - **DNSCat2** — инструмент для эксфильтрации данных через DNS-запросы.
    - **Covenant** — фреймворк для эксфильтрации данных с поддержкой скрытых методов передачи информации.

##### **4. Анализ системы и сети**

Злоумышленник может провести полный анализ системы и сети, чтобы получить представление о внутренней структуре, выявить слабые места и уязвимые системы, а также расширить свое присутствие в инфраструктуре. Основные цели:

- **Определение важности систем** — поиск критически важных систем или сетевых узлов, к которым можно попытаться получить доступ.
    
- **Поиск других уязвимых машин** — анализ открытых портов, сервисов и потенциальных уязвимостей на других машинах в сети.
    
    **Инструменты**:
    
    - **nmap** — для сканирования сети и поиска открытых портов и сервисов на других узлах.
    - **BloodHound** — инструмент для анализа отношений доверия в Active Directory и поиска путей для дальнейшего проникновения.

##### **5. Lateral Movement (горизонтальное перемещение)**

После закрепления на одной машине злоумышленник может использовать её как точку для распространения атаки на другие узлы в сети. Для этого используются методы горизонтального перемещения (Lateral Movement):

- **Pass-the-Hash** — злоумышленник использует хеш пароля, а не сам пароль, для аутентификации на других машинах.
    
- **Pass-the-Ticket** — метод атак на системы с Kerberos-аутентификацией, когда используются сессионные билеты для доступа.
    
- **Remote Desktop Protocol (RDP)** — использование RDP для удалённого подключения к другим машинам.
    
    **Инструменты**:
    
    - **PsExec** — утилита для удалённого выполнения команд на машинах Windows.
    - **Impacket** — набор инструментов для выполнения атак Pass-the-Hash, Pass-the-Ticket и SMB-протоколов.
    - **CrackMapExec** — многофункциональный инструмент для проведения атак на Active Directory и Windows.

##### **6. Удаление следов (Covering Tracks)**

Для того чтобы избежать обнаружения и предотвращения атаки, злоумышленник должен скрыть свои действия. Это может включать:

- **Удаление логов** — удаление или подделка записей логов, которые могли бы указывать на аномальную активность.
    
- **Изменение временных меток файлов** — подделка времени изменения файлов для скрытия следов изменения системы.
    
- **Удаление или шифрование инструментов** — удаление всех использованных утилит или шифрование вредоносных программ для затруднения анализа.
    
    **Инструменты**:
    
    - **Metasploit** — модуль для очистки следов из логов.
    - **wevtutil** — утилита для управления журналами событий в Windows, включая их удаление.
    - **Timestamp-modification tools** — утилиты для изменения временных меток файлов и программ.
