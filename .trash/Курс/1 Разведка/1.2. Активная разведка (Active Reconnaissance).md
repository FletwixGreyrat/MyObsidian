
#### **1.2. Активная разведка (Active Reconnaissance)**

Активная разведка подразумевает прямое взаимодействие с целевой системой для получения дополнительной информации. Этот метод более рискованный, так как целевая система может зафиксировать такие действия, но и более эффективный в плане сбора данных.

##### Методы и инструменты:

1. **Сканирование портов (Port Scanning)**
    
    - Используется для выявления открытых портов и служб на целевом сервере. Открытые порты могут указать на запущенные приложения и сервисы (например, веб-серверы, базы данных, FTP).
    - Инструмент **Nmap** позволяет провести сканирование открытых портов и получить информацию о запущенных сервисах. Это важно для дальнейшего анализа на уязвимости.
        - Пример команды: `nmap -sS -sV example.com` — определение версии сервиса на открытых портах.
2. **Banner Grabbing**
    
    - Цель — получение информации о сервисах и их версиях через анализ "баннеров", которые они отправляют при соединении. Это помогает идентифицировать уязвимые версии ПО.
    - Инструменты:
        - **Telnet** или **Netcat** для подключения к сервисам и анализа баннеров.
        - **Nmap** — поддерживает автоматическое извлечение баннеров.
3. **Сканирование уязвимостей веб-приложений (Web Application Vulnerability Scanning)**
    
    - Использование автоматизированных инструментов для выявления потенциальных уязвимостей, таких как XSS, SQL-инъекции и другие.
    - Инструменты:
        - **OWASP ZAP** — автоматический сканер для тестирования безопасности веб-приложений.
        - **Burp Suite** — сканер для анализа безопасности веб-приложений, который поддерживает ручное тестирование и автоматическое сканирование.
4. **Сбор сведений о сертификатах**
    
    - Анализ SSL/TLS сертификатов веб-сайта может дать информацию о безопасности соединений, конфигурации сервера и других аспектах.
    - Инструменты:
        - **SSL Labs** для проверки конфигурации HTTPS-соединений и сертификатов.
5. **Проверка доступных файлов и директорий (Directory and File Brute Forcing)**
    
    - Использование брутфорсинга для поиска скрытых директорий и файлов, которые не перечислены явно на веб-сайте, но могут содержать важную информацию.
    - Инструменты:
        - **Gobuster** или **DirBuster** для перебора возможных путей на сервере.
