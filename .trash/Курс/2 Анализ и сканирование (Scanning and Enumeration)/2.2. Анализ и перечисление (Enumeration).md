
##### **1. Перечисление служб (Service Enumeration)**

Этот этап включает детальное изучение всех служб, которые были обнаружены во время сканирования портов. Хакер анализирует версии программного обеспечения и пытается найти уязвимости для эксплуатации.

- **SNMP Enumeration** — получение информации через Simple Network Management Protocol (SNMP). Это может дать сведения о сетевых устройствах и их конфигурации.
    
    - Инструмент: **snmpwalk**.
- **SMB Enumeration** — перечисление общих ресурсов и пользователей через протокол Server Message Block (SMB), который часто используется в сетях Windows.
    
    - Инструменты:
        - **enum4linux** для сканирования SMB-служб в сетях Windows.
        - **smbclient** для соединения с общими SMB-ресурсами.

##### **2. Перечисление пользователей и групп (User Enumeration)**

В некоторых веб-приложениях или сервисах могут быть уязвимости, позволяющие перечислять пользователей системы, что может помочь в атаке на авторизацию (например, подбор паролей).

- **LDAP Enumeration** — используется для получения информации из служб каталогов (например, Active Directory).
    
    - Инструмент: **ldapsearch** для поиска пользователей в LDAP.
- **Перечисление через веб-формы**: В некоторых случаях, вводя неправильные данные, можно получить подсказки от системы о существующих пользователях или группах.
    

##### **3. Перечисление доменов и поддоменов (Domain Enumeration)**

Часто веб-приложения или организации используют несколько поддоменов для различных сервисов. Эти поддомены могут быть менее защищены, чем основной сайт, и служить точкой входа для атаки.

- **Sublist3r** — инструмент для поиска поддоменов веб-сайта.
    
- **Amass** — мощный инструмент для поиска поддоменов и анализа сетевой инфраструктуры.
    

##### **4. Анализ баннеров (Banner Grabbing)**

Анализ баннеров позволяет узнать версию программного обеспечения, работающее на целевом сервере. Эти данные могут быть использованы для дальнейшего анализа уязвимостей.

- **Telnet** или **Netcat** — можно использовать для подключения к открытым портам и анализа ответов серверов.

##### **5. Сканирование конфигураций SSL/TLS (SSL/TLS Enumeration)**

Проверка безопасности соединений, используемых сервером (например, SSL/TLS), чтобы узнать, правильно ли настроены шифрование и сертификаты.

- **SSL Labs** — веб-инструмент для анализа конфигураций SSL/TLS.
- **testssl.sh** — утилита для проверки уязвимостей SSL/TLS на сервере.
