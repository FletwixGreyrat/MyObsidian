
##### **1. Сканеры уязвимостей (Vulnerability Scanners)**

Автоматизированные сканеры помогают выявлять известные уязвимости в веб-приложениях и системах. Они используют базы данных уязвимостей, такие как CVE (Common Vulnerabilities and Exposures), и проводят автоматическую проверку.

- **Nessus** — один из самых популярных сканеров уязвимостей. Он проводит анализ сети, приложений и операционных систем на предмет известных уязвимостей и предоставляет подробные отчеты.
    
- **OpenVAS** — бесплатный аналог Nessus. Этот инструмент также ищет уязвимости в системе, используя базы данных известных уязвимостей.
    
- **Acunetix** — сканер, специально предназначенный для анализа веб-приложений. Он проверяет на наличие таких уязвимостей, как SQL-инъекции, XSS, CSRF и другие.
    
- **OWASP ZAP** — мощный инструмент с открытым исходным кодом для сканирования веб-приложений на уязвимости. Он может автоматически обнаруживать общие уязвимости, такие как XSS и CSRF.
    
- **Burp Suite** — еще один популярный инструмент для тестирования веб-приложений. Он поддерживает автоматическое сканирование уязвимостей и ручное тестирование.
    

##### **2. Поиск уязвимых версий ПО**

Инструменты сканирования могут выявить версии сервисов и программного обеспечения, которые используются на целевом сервере. Эти версии могут быть проверены на наличие известных уязвимостей через базы данных уязвимостей, такие как:

- **CVE** — глобальная база данных известных уязвимостей.
- **Exploit Database (Exploit-DB)** — база данных эксплойтов, где можно найти готовые эксплойты для использования известных уязвимостей.
- **NVD (National Vulnerability Database)** — национальная база данных уязвимостей, поддерживаемая правительством США.

##### **3. Ручной анализ**

Автоматизированные инструменты не всегда могут обнаружить все уязвимости. В таких случаях применяется ручной анализ.

- **Burp Suite** — также может использоваться для ручного тестирования веб-приложений. С его помощью можно перехватывать запросы и изменять их содержимое для проверки безопасности веб-приложения (например, тестирование на SQL-инъекции, манипуляции с параметрами).
    
- **Wireshark** — инструмент для анализа сетевого трафика. Он позволяет исследовать данные, передаваемые между клиентом и сервером, и искать уязвимости, связанные с неправильной передачей данных.
    
- **Metasploit** — инструмент для разработки и запуска эксплойтов. С его помощью можно проверить, могут ли обнаруженные уязвимости быть успешно использованы.
    

##### **4. Сканирование конфигураций SSL/TLS**

SSL/TLS является важной частью безопасности веб-сайтов. Неправильная настройка этих протоколов может привести к уязвимостям, таким как уязвимость **Heartbleed**.

- **testssl.sh** — утилита для анализа конфигураций SSL/TLS и поиска возможных уязвимостей.
- **SSL Labs** — веб-инструмент для анализа конфигурации SSL/TLS-сертификатов на веб-сайтах.
