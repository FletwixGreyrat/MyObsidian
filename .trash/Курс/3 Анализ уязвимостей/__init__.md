### 3. **Анализ уязвимостей (Vulnerability Assessment)**

Этот этап включает в себя поиск уязвимостей, которые могут быть использованы для взлома. Этичные хакеры используют как ручные методы анализа, так и автоматизированные сканеры.

- **SQL-инъекции (SQL Injection)**: Использование **SQLMap** для автоматизированного поиска SQL-инъекций.
- **XSS (Cross-Site Scripting)**: Проверка возможностей внедрения вредоносного JavaScript кода через формы ввода.
- **CSRF (Cross-Site Request Forgery)**: Анализ токенов сессии и возможности подмены запросов.
- **Сканирование на уязвимости**: Использование **Burp Suite**, **OWASP ZAP** или других инструментов для поиска распространенных уязвимостей, таких как CSRF, XSS, LFI, RFI и другие.

### **Выводы этапа анализа уязвимостей**

По завершению этого этапа, специалист по безопасности должен иметь чёткое представление о:

1. **Количество и типы уязвимостей** в системе.
2. **Потенциальные риски** для бизнеса и данных.
3. **Способы эксплуатации уязвимостей** и возможные последствия.
4. **Рекомендации по устранению** этих уязвимостей.

Эти результаты играют решающую роль на следующих этапах — **эксплуатации** и **эскалации привилегий**.
