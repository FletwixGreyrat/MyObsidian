
Существует множество методов для достижения эскалации привилегий. Наиболее распространённые методы включают эксплуатацию уязвимостей операционных систем, приложений, некорректно настроенных сервисов, а также использование неправильно хранимых паролей.

##### **1. Эксплуатация уязвимостей операционной системы**

Некоторые версии операционных систем содержат уязвимости, которые могут быть использованы для эскалации привилегий. Это может быть либо локальная уязвимость, которая требует физического или удаленного доступа, либо удалённая уязвимость, эксплуатируемая через сеть.

- **Инструменты**:
    - **Metasploit** — содержит эксплойты для эскалации привилегий на различных операционных системах.
        
    - **Exploit-DB** — база данных готовых эксплойтов, которые можно использовать для атаки на уязвимые системы.
        
    - **Пример**: Уязвимость в ядре Linux или Windows может позволить злоумышленнику, используя команду на уровне пользователя, получить права root или SYSTEM.
        

##### **2. Неправильные разрешения файлов и директорий**

Если важные системные файлы или директории имеют неправильные разрешения, злоумышленник может их прочитать или изменить, что может привести к повышению привилегий.

- **Пример**: Файл пароля или конфигурационный файл, доступный для чтения обычному пользователю, может содержать чувствительную информацию (пароли, ключи), которые позволят получить доступ к более привилегированным учетным записям.
    
    - **Инструменты**:
        - **LinPEAS** — сканер для обнаружения потенциальных путей эскалации привилегий в системах на базе Linux.
        - **WinPEAS** — аналог для Windows, который сканирует систему на наличие уязвимостей и неправильных конфигураций, которые могут быть использованы для эскалации прав.

##### **3. Использование слабых паролей или хранимых паролей**

Если в системе хранятся пароли или хеши паролей (например, в файле конфигурации), и они защищены недостаточно надёжно, злоумышленник может попытаться их использовать для получения прав доступа к учетной записи с более высокими привилегиями.

- **Пример**: Пароль администратора может быть сохранён в файле конфигурации веб-сервера или базы данных. Если файл неправильно защищён, злоумышленник может прочитать его и получить доступ к административной учетной записи.
    
    - **Инструменты**:
        - **John the Ripper** или **Hashcat** — инструменты для перебора и расшифровки паролей и хешей.

##### **4. Уязвимые сервисы и неправильно настроенные службы**

Некоторые сервисы и службы, работающие с повышенными привилегиями, могут быть настроены неправильно, что позволяет злоумышленнику использовать их для повышения прав доступа.

- **Пример**: Неправильно настроенный сервис на Windows может быть использован для выполнения команд с привилегиями SYSTEM.
    
    - **Инструменты**:
        - **Watson** — инструмент для обнаружения потенциальных путей эскалации привилегий в системах на базе Windows.
        - **GTFOBins** — база данных с примерами того, как можно использовать стандартные системные утилиты для повышения прав доступа в Linux.

##### **5. Эксплуатация уязвимостей в драйверах и модулях ядра**

Некоторые уязвимости в драйверах устройств или модулях ядра могут быть использованы для получения более высоких привилегий.

- **Пример**: Уязвимость в драйвере сетевого адаптера может позволить злоумышленнику с правами обычного пользователя выполнять команды на уровне ядра ОС.

##### **6. Использование слабых скриптов или программ, работающих от имени администратора**

Если скрипты или программы, которые выполняются с привилегиями администратора, имеют уязвимости или неправильно настроены, их можно использовать для выполнения произвольного кода.

- **Пример**: Скрипт, который выполняется от имени root, но имеет возможность принимать ввод от пользователя, может быть использован для выполнения произвольных команд.
